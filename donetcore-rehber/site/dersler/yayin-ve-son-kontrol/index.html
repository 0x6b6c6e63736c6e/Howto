Eğitim sitesini Cloudflare Pages’e hazırla

Eğitim sitesi statik HTML, CSS, JavaScript ve indirilebilir örneklerden oluşur. Cloudflare Pages projesi dotnetatolye için yayın kökü site dizinidir. Direct Upload seçersen ZIP’in kökünde index.html ve dersler bulunmalıdır.

Git entegrasyonunda depo kökü bu projenin kökü ise build komutu exit 0, çıktı dizini site olarak ayarlanabilir. Direct Upload projesi daha sonra Git entegrasyonuna dönüştürülemez. Git entegrasyonu istenirse proje oluştururken bu yöntem seçilmelidir.

Yayın sonrasında ana sayfayı, ders bağlantılarını, mobil menüyü ve örnek indirmeyi canlı adreste kontrol et.

Etkinlik uygulamasını Release olarak paketle

Etkinlik uygulaması .NET 10 ve SQL Server kullanan ayrı bir uygulamadır. ZIP içindeki ders klasöründen aşağıdaki komut framework-dependent paket üretir. Hedef sunucuda .NET 10 ASP.NET Core runtime bulunmalıdır.

Terminal
dotnet publish Etkinlikler/Etkinlikler.csproj -c Release -o ./publish

Çıktıdaki Etkinlikler.dll uygulama sunucusunda çalıştırılır. Sunucu işletim sistemine uygun süreç yöneticisi, HTTPS ve gerekiyorsa ters proxy yapılandırılır.

SQL Server ve migration hazırlığı

Uygulamanın ConnectionStrings:EtkinlikDb ayarı erişilebilir SQL Server’ı göstermelidir. EF Core SQL Server sağlayıcısı ve Identity tabloları aynı veritabanını kullanır. Migration betiğini üret ve hedef veritabanının geçmişine uygunluğunu incele.

Terminal · Etkinlikler proje klasöründen
dotnet tool restore
dotnet ef migrations script --idempotent -o migrations.sql

Şema değişikliklerini hedef ortamda uygulamadan önce geri yüklenebilir yedek al ve betiği test veritabanında doğrula. Migration için şema değiştirme yetkisi, uygulama hesabı için gerekli okuma ve yazma yetkileri gerekir. Uygulama açılışta migration çalıştırmaz.

Ortam ayarları ve kimlik doğrulama

Üretim ortamı bağlantı dizesini güvenli yapılandırma kaynağından sağlar. JWT doğrulaması için Jwt:Key, Jwt:Issuer ve Jwt:Audience ayarları da gerekir. Eğitim amaçlı /api/token ucu Production ortamında kapalıdır. API yazma uçlarını üretimde kullanmak için güvenilir bir OAuth/OIDC kimlik sağlayıcısı ve bu sağlayıcıya uygun JWT doğrulaması ayrıca kurulmalıdır.

Yönetim oturumu Identity çerezi kullanır. HTTPS, kalıcı Data Protection anahtarları ve çoklu sunucu kullanılıyorsa paylaşılan anahtar deposu ortamına göre yapılandırılmalıdır. User Secrets yerel geliştirme içindir.

Kontrol sonuçları ve yayın sonrası

Bu dersin yerel Release paketi derlendi. Production modunda giriş sayfası HTTP 200 döndürdü ve eğitim token ucu 404 verdi. Migration modeliyle uyumlu SQL betiği üretildi. SQL Server bağlantısı, migration uygulaması, kullanıcı girişi ve API işlemleri canlı veritabanında henüz doğrulanmadı.

Önce test ortamında migration, kullanıcı girişi, rol yetkileri, API ve eşzamanlı kayıt akışını doğrula. Ardından hedef ortamda yayın sonrası aynı kontrolleri yap ve logları incele.
