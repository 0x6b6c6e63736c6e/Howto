Test ve yayın hazırlığı

Yönetim ekranlarını otomatik test et, Release paketi oluştur ve uygulamayı yayın için hazırla.

Test projesi

Örnek çözümdeki WebApplicationFactory uygulamayı test sunucusunda başlatır. Üç yönetim adresine oturumsuz istek gönderilir ve giriş sayfasına yönlendirme doğrulanır. Dördüncü test giriş formunun açıldığını ve doğrulama belirteci içerdiğini kontrol eder.

Terminal · ZIP içindeki ders klasöründen
dotnet test Etkinlikler.Tests/Etkinlikler.Tests.csproj
Etkinlikler.Tests/YetkilendirmeTestleri.cs
using System.Net;
using Microsoft.AspNetCore.Hosting;
using Microsoft.AspNetCore.Mvc.Testing;
using Microsoft.Extensions.Configuration;
using Xunit;

namespace Etkinlikler.Tests;

public class YetkilendirmeTestleri
{
    private static WebApplicationFactory<Program> Uygulama() =>
        new WebApplicationFactory<Program>().WithWebHostBuilder(builder =>
            builder.ConfigureAppConfiguration((_, config) =>
                config.AddInMemoryCollection(new Dictionary<string, string?>
                {
                    ["ConnectionStrings:EtkinlikDb"] = "Server=localhost;Database=Test;Integrated Security=True;Encrypt=True"
                })));

    [Theory]
    [InlineData("/Etkinlikler/Ekle")]
    [InlineData("/Etkinlikler/Doluluk")]
    [InlineData("/Kayitlar/Ekle")]
    public async Task Anonim_kullanici_girise_yonlendirilir(string adres)
    {
        await using var app = Uygulama();
        using var client = app.CreateClient(new WebApplicationFactoryClientOptions { AllowAutoRedirect = false });
        using var response = await client.GetAsync(adres);

        Assert.Equal(HttpStatusCode.Redirect, response.StatusCode);
        Assert.Equal("/Hesap/Giris", response.Headers.Location!.AbsolutePath);
    }

    [Fact]
    public async Task Giris_formu_anonim_erisimde_acilir()
    {
        await using var app = Uygulama();
        using var client = app.CreateClient();
        using var response = await client.GetAsync("/Hesap/Giris");

        Assert.Equal(HttpStatusCode.OK, response.StatusCode);
        Assert.Contains("__RequestVerificationToken", await response.Content.ReadAsStringAsync());
    }
}

Bu testler SQL Server bağlantısını açmaz. Gerçek kullanıcı, rol, kayıt işlemi ve eşzamanlı kontenjan testleri için ayrı bir test SQL Server veritabanı gerekir. Üretim verilerini testlerde kullanma.

Release paketi üret

Testler geçtikten sonra uygulamayı ayrı bir dizine yayınla. Çıktı framework-dependent pakettir ve çalışacağı sunucuda .NET 10 ASP.NET Core runtime bulunmalıdır.

Terminal · Yerel paket
dotnet publish Etkinlikler/Etkinlikler.csproj -c Release -o ./publish

Paket sunucuya aktarılmadan önce hedef ortama ait bağlantı bilgisini güvenli yapılandırma üzerinden sağla. User Secrets geliştirme içindir. Uygun bağlantıyla migration SQL betiğini üretip incele, ardından hedef veritabanında kontrollü uygula.

Terminal · Migration SQL
cd Etkinlikler
dotnet tool restore
ASPNETCORE_ENVIRONMENT=Development dotnet ef migrations script --idempotent -o ../migrations.sql

Yayın öncesi ve sonrası kontrol

Uygulama sunucusunda HTTPS, bağlantı ayarları ve veritabanı erişimini doğrula. Migration öncesinde veritabanının geri yüklenebilir yedeğini al. Yayın sonrası giriş, yönetici ve rolü olmayan kullanıcı erişimi, katılımcı kaydı ve doluluk raporunu ayrı test verileriyle kontrol et.

Cloudflare Pages eğitim sitesinin statik dosyalarını sunar. Bu dersin ASP.NET Core uygulaması .NET çalıştıran ayrı bir uygulama sunucusu ve erişilebilir SQL Server gerektirir.

Alıştırma

Testlere /Etkinlikler/Ekle adresine anonim POST isteği için yönlendirme kontrolü ekle. Ayrı bir test veritabanı kurduğunda yönetici, rolü olmayan kullanıcı ve eşzamanlı son yer senaryolarını da test et.
