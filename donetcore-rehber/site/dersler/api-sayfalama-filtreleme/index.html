API sayfalama, filtreleme ve sıralama

Etkinlikleri sorgu parametreleriyle filtrele, sırala ve sayfalar hâlinde getir.

.NET 10Ders 11Yaklaşık 35 dakika
Ön koşul

Onuncu dersin etkinlik API’si ve SQL Server bağlantısı.

Örnek projeyi indir

Sorgu parametreleri

GET /api/etkinlikler parametresiz çağrıldığında ilk 10 etkinliği kimliğe göre artan sıralar. sayfa 1’den başlar ve en fazla 1.000.000 olabilir. sayfaBoyutu 1–100 arasındadır. arama etkinlik adında metin arar, enAzKontenjan alt sınır uygular. sirala için id, ad veya kontenjan, yon için artan veya azalan seçilir.

Sayfa boş olsa da toplamKayit filtreyle eşleşen tüm etkinliklerin sayısını gösterir. İzin verilmeyen değerler ve sayıya çevrilemeyen parametreler 400 döndürür.

Sorgu modelini oluştur

[FromQuery] adres parametrelerini modele bağlar. [ApiController] veri türü ve doğrulama hatalarında 400 yanıtı üretir. Arama için boş veya yalnızca boşluktan oluşan değer filtre uygulanmadan işlenir.

Models/EtkinlikSorgusu.cs
using System.ComponentModel.DataAnnotations;

namespace Etkinlikler.Models;

public sealed class EtkinlikSorgusu
{
    [Range(1, 1_000_000)]
    public int Sayfa { get; set; } = 1;

    [Range(1, 100)]
    public int SayfaBoyutu { get; set; } = 10;

    [StringLength(80)]
    public string? Arama { get; set; }

    [Range(1, 500)]
    public int? EnAzKontenjan { get; set; }

    [RegularExpression("^(id|ad|kontenjan)$", ErrorMessage = "Sıralama id, ad veya kontenjan olmalı.")]
    public string Sirala { get; set; } = "id";

    [RegularExpression("^(artan|azalan)$", ErrorMessage = "Yön artan veya azalan olmalı.")]
    public string Yon { get; set; } = "artan";
}

Filtrele, sırala ve sayfala

Filtreler önce uygulanır ve CountAsync toplam eşleşme sayısını alır. OrderBy ve ThenBy sıralamayı belirler. Ad veya kontenjan eşitse kimlik ikinci anahtar olur. Skip önceki sayfaların kayıtlarını geçer, Take yalnızca istenen sayfayı getirir.

EtkinliklerApiController.cs · Listele
[HttpGet]
    public async Task<IActionResult> Listele([FromQuery] EtkinlikSorgusu istek, CancellationToken cancellationToken)
    {
        var sorgu = db.Etkinlikler.AsNoTracking().AsQueryable();
        if (!string.IsNullOrWhiteSpace(istek.Arama))
        {
            var arama = istek.Arama.Trim();
            sorgu = sorgu.Where(e => e.Ad.Contains(arama));
        }
        if (istek.EnAzKontenjan.HasValue)
            sorgu = sorgu.Where(e => e.Kontenjan >= istek.EnAzKontenjan.Value);

        var toplam = await sorgu.CountAsync(cancellationToken);
        var azalan = istek.Yon == "azalan";
        sorgu = istek.Sirala switch
        {
            "ad" when azalan => sorgu.OrderByDescending(e => e.Ad).ThenBy(e => e.Id),
            "ad" => sorgu.OrderBy(e => e.Ad).ThenBy(e => e.Id),
            "kontenjan" when azalan => sorgu.OrderByDescending(e => e.Kontenjan).ThenBy(e => e.Id),
            "kontenjan" => sorgu.OrderBy(e => e.Kontenjan).ThenBy(e => e.Id),
            _ when azalan => sorgu.OrderByDescending(e => e.Id),
            _ => sorgu.OrderBy(e => e.Id)
        };

        var kayitlar = await sorgu.Skip((istek.Sayfa - 1) * istek.SayfaBoyutu)
            .Take(istek.SayfaBoyutu).ToListAsync(cancellationToken);
        return Ok(new { istek.Sayfa, istek.SayfaBoyutu, toplamKayit = toplam, kayitlar });
    }

Bu sorgu SQL Server’a çevrilir. Aramanın büyük-küçük harf ve Türkçe karakter eşleşmesi veritabanı collation ayarına bağlıdır. Toplam ve sayfa iki ayrı sorgudur. Aralarında veri değişirse anlık değerler farklılaşabilir. Offset sayfalama sırasında kayıt eklenmesi veya silinmesi sayfalar arasında kayma oluşturabilir.

İstek ve yanıt örnekleri

Örnek projeyi dokuzuncu dersteki SQL Server bağlantısıyla başlat. Yeni migration gerekmez.

Terminal · ZIP içindeki ders klasöründen
ASPNETCORE_ENVIRONMENT=Development dotnet run --project Etkinlikler --no-launch-profile --urls http://localhost:5088

İstekleri terminalde çalıştır. URL içindeki & karakterleri için adresi tırnak içinde tut.

Terminal
curl 'http://localhost:5088/api/etkinlikler?sayfa=1&sayfaBoyutu=1'
curl 'http://localhost:5088/api/etkinlikler?arama=SQL&enAzKontenjan=30'
curl 'http://localhost:5088/api/etkinlikler?sirala=kontenjan&yon=azalan'
curl 'http://localhost:5088/api/etkinlikler?sayfaBoyutu=101'

İlk istek başlangıç verilerinde aşağıdaki yapıyı verir.

JSON
{
  "sayfa": 1,
  "sayfaBoyutu": 1,
  "toplamKayit": 2,
  "kayitlar": [
    { "id": 1, "ad": "Web Geliştirme Atölyesi", "kontenjan": 25 }
  ]
}

Önceki dersin liste yanıtı doğrudan bir JSON dizisiydi. Bu derste yanıt sayfa bilgileri ve kayitlar dizisini içeren nesnedir. Mevcut API istemcileri bu yeni yapıya göre güncellenmelidir.
