MVC temelleri ve form doğrulama

Etkinlik listesine bir ekleme formu bağla. Form verisinin Razor’dan controller’a nasıl ulaştığını izle ve geçersiz girişleri kullanıcıya göster.

.NET 10Ders 2Yaklaşık 30 dakika
Ön koşul

.NET 10 SDK ve ilk dersteki etkinlik listesi. Örneği indirerek tamamlanmış projeyi çalıştırabilir veya ilk dersteki dosyaları adım adım güncelleyebilirsin.

Örnek projeyi indir

MVC’de istek nasıl ilerler?

GET /Etkinlikler/Ekle isteği boş formu açar. Kaydet düğmesi aynı adrese POST gönderir. Routing, adres ve HTTP yöntemine göre doğru action’ı seçer. Model binding form alanlarını EtkinlikFormu özelliklerine dönüştürür ve MVC doğrulama kurallarını çalıştırır.

Controller geçersiz gönderimde aynı view’ı döndürür. Kullanıcının girdiği değerler ve hata mesajları ModelState üzerinden ekrana gelir. Başarılı gönderim ise listeyi açan yeni bir GET isteğine yönlendirilir. Bu akışa Post/Redirect/Get denir ve listeyi yenilemek formu tekrar göndermez.

Form modelini tanımla

Projede Models/EtkinlikFormu.cs dosyasını oluştur. Form modelinde yalnızca kullanıcıdan kabul ettiğin alanları tanımla. int? sayesinde boş kontenjan ile girilmiş 0 ayrı doğrulama mesajları üretebilir. Sayıya çevrilemeyen değer ise model binding hatasıdır.

Models/EtkinlikFormu.cs
using System.ComponentModel.DataAnnotations;

namespace Etkinlikler.Models;

public sealed class EtkinlikFormu
{
    [Display(Name = "Etkinlik adı")]
    [Required(ErrorMessage = "Etkinlik adını girin.")]
    [StringLength(80, MinimumLength = 3,
        ErrorMessage = "Etkinlik adı 3 ile 80 karakter arasında olmalı.")]
    public string? Ad { get; set; }

    [Required(ErrorMessage = "Kontenjanı girin.")]
    [Range(1, 500, ErrorMessage = "Kontenjan 1 ile 500 arasında olmalı.")]
    public int? Kontenjan { get; set; }
}

Etkinlik listesini servise taşı

İlk dersteki diziyi bir liste servisine taşı. Etkinlik kaydı, liste ekranının göstereceği adı ve kontenjanı taşır. Servis bir kopya döndürür ve eşzamanlı okuma ile eklemeleri kilit altında yürütür.

Models/EtkinlikListesi.cs
namespace Etkinlikler.Models;

public sealed record Etkinlik(string Ad, int Kontenjan);

public sealed class EtkinlikListesi
{
    private readonly object kilit = new();
    private readonly List<Etkinlik> etkinlikler =
    [
        new("Web Geliştirme Atölyesi", 25),
        new("SQL Server Semineri", 40)
    ];

    public IReadOnlyList<Etkinlik> Listele()
    {
        lock (kilit)
        {
            return etkinlikler.ToArray();
        }
    }

    public void Ekle(Etkinlik etkinlik)
    {
        lock (kilit)
        {
            etkinlikler.Add(etkinlik);
        }
    }
}

AddSingleton sayesinde GET ve POST istekleri aynı listeyi kullanır. Eklenen kayıtlar uygulama yeniden başladığında silinir. EF Core bölümünde kalıcı veritabanı bağlantısı ekleyeceğiz.

Program.cs
using Etkinlikler.Models;

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllersWithViews();
builder.Services.AddSingleton<EtkinlikListesi>();

var app = builder.Build();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Etkinlikler}/{action=Index}/{id?}");

app.Run();

GET ve POST action’larını yaz

[HttpGet] boş formu açar. [HttpPost] gönderimi alır. [ValidateAntiForgeryToken], Form Tag Helper’ın ürettiği doğrulama belirtecini kontrol eder. ModelState.IsValid başarılıysa zorunlu alanlar ve kontenjan aralığı doğrulanmış olur.

Controllers/EtkinliklerController.cs
using Etkinlikler.Models;
using Microsoft.AspNetCore.Mvc;

namespace Etkinlikler.Controllers;

public class EtkinliklerController(EtkinlikListesi liste) : Controller
{
    [HttpGet]
    public IActionResult Index() => View(liste.Listele());

    [HttpGet]
    public IActionResult Ekle() => View(new EtkinlikFormu());

    [HttpPost]
    [ValidateAntiForgeryToken]
    public IActionResult Ekle(EtkinlikFormu form)
    {
        if (!ModelState.IsValid)
        {
            return View(form);
        }

        liste.Ekle(new Etkinlik(form.Ad!, form.Kontenjan!.Value));
        return RedirectToAction(nameof(Index));
    }
}

Razor ve Tag Helpers ile formu bağla

Views/_ViewImports.cshtml dosyası Razor sayfalarına model ad alanını ve MVC Tag Helpers desteğini ekler.

Views/_ViewImports.cshtml
@using Etkinlikler.Models
@addTagHelper *, Microsoft.AspNetCore.Mvc.TagHelpers

asp-action form adresini, asp-for alan adı ve etiketini, asp-validation-for alanın hata mesajını üretir. Örnekte doğrulama mesajlarını Kaydet’e bastıktan sonra sunucu döndürür.

Views/Etkinlikler/Ekle.cshtml
@model EtkinlikFormu
<!doctype html>
<html lang="tr">
<head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Etkinlik ekle</title>
    <style>
        body { font: 1rem/1.5 system-ui, sans-serif; max-width: 34rem; margin: 2rem auto; padding: 0 1rem; }
        label, input, .field-validation-error { display: block; }
        input { box-sizing: border-box; width: 100%; padding: .5rem; font: inherit; }
        .field-validation-error { color: #a42028; }
        button { font: inherit; padding: .45rem .8rem; }
    </style>
</head>
<body>
    <main>
        <h1>Etkinlik ekle</h1>
        <form asp-action="Ekle" method="post">
            <p>
                <label asp-for="Ad"></label>
                <input asp-for="Ad" aria-describedby="ad-hata" />
                <span id="ad-hata" asp-validation-for="Ad"></span>
            </p>
            <p>
                <label asp-for="Kontenjan"></label>
                <input asp-for="Kontenjan" aria-describedby="kontenjan-hata" />
                <span id="kontenjan-hata" asp-validation-for="Kontenjan"></span>
            </p>
            <p><button type="submit">Kaydet</button></p>
        </form>
        <p><a asp-action="Index">Listeye dön</a></p>
    </main>
</body>
</html>

Liste view’ı artık IReadOnlyList<Etkinlik> alır. Oluşturma bağlantısı da Tag Helper ile üretilir.

Views/Etkinlikler/Index.cshtml
@model IReadOnlyList<Etkinlik>
<!doctype html>
<html lang="tr">
<head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Etkinlikler</title>
</head>
<body>
    <h1>Etkinlikler</h1>
    <p><a asp-action="Ekle">Etkinlik ekle</a></p>
    <ul>
        @foreach (var etkinlik in Model)
        {
            <li>@etkinlik.Ad (@etkinlik.Kontenjan kişilik)</li>
        }
    </ul>
</body>
</html>

dotnet run --no-launch-profile --urls http://localhost:5081
