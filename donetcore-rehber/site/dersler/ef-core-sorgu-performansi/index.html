EF Core sorgu performansı

Aynı etkinlik raporunda Include, projection, AsNoTracking ve N+1 yaklaşımını karşılaştır.

.NET 10Ders 15Yaklaşık 40 dakika

Örnek projeyi indir

Aynı raporu dört şekilde oku

Her yöntem etkinlik kimliği, adı ve katılımcı adlarını döndürür. İlk örnek etkinlikleri okur, ardından her etkinlik için ayrı katılımcı sorgusu çalıştırır. Bu açıkça yazılmış döngü N+1 davranışını gösterir. Projede lazy loading etkin değildir.

YöntemKomutİzlenen varlık
N+1, izleme kapalı30
Include18
Include + AsNoTracking10
Projection10

Tablo, iki etkinlik ve üç kayıt içeren SQLite testinin ölçümüdür. N+1 için sayı bir liste komutu ve etkinlik başına bir komuttur. İzlenen sekiz varlık iki etkinlik, üç kayıt ve üç katılımcıdır. Her yöntem ayrı bir DbContext kullanır.

Sorgular ve komut sayacı

Include ilişkili varlıkları yükler. AsSingleQuery bu karşılaştırmada tek sorgu davranışını açıkça seçer. AsNoTracking okunan varlıkları değişiklik takibine eklemez. Projection, Select ile raporun ihtiyaç duyduğu veriyi seçer.

Data/SorguKarsilastirmasi.cs
using System.Data.Common;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Diagnostics;

namespace Etkinlikler.Data;

public sealed class KomutSayaci : DbCommandInterceptor
{
    public List<string> Komutlar { get; } = [];

    public override ValueTask<InterceptionResult<DbDataReader>> ReaderExecutingAsync(
        DbCommand command, CommandEventData eventData,
        InterceptionResult<DbDataReader> result, CancellationToken cancellationToken = default)
    {
        Komutlar.Add(command.CommandText);
        return ValueTask.FromResult(result);
    }
}

public sealed record RaporSatiri(int Id, string Etkinlik, IReadOnlyList<string> Katilimcilar);
public sealed record Olcum(string Yontem, int KomutSayisi, int IzlenenVarlik,
    IReadOnlyList<RaporSatiri> Sonuc, IReadOnlyList<string> Sql);

public static class SorguKarsilastirmasi
{
    public static async Task<IReadOnlyList<Olcum>> CalistirAsync(
        Func<KomutSayaci, EtkinlikDbContext> contextOlustur, CancellationToken cancellationToken = default)
    {
        var sonuclar = new List<Olcum>();
        foreach (var yontem in new[] { "N+1", "Include", "Include + AsNoTracking", "Projection" })
        {
            var sayac = new KomutSayaci();
            await using var db = contextOlustur(sayac);
            List<RaporSatiri> rapor;

            if (yontem == "N+1")
            {
                var etkinlikler = await db.Etkinlikler.AsNoTracking().OrderBy(e => e.Id).ToListAsync(cancellationToken);
                rapor = [];
                foreach (var etkinlik in etkinlikler)
                {
                    var adlar = await db.EtkinlikKayitlari.AsNoTracking()
                        .Where(k => k.EtkinlikId == etkinlik.Id)
                        .OrderBy(k => k.KatilimciId)
                        .Select(k => k.Katilimci.Ad).ToListAsync(cancellationToken);
                    rapor.Add(new RaporSatiri(etkinlik.Id, etkinlik.Ad, adlar));
                }
            }
            else if (yontem == "Projection")
            {
                var satirlar = await db.Etkinlikler.AsNoTracking().OrderBy(e => e.Id)
                    .Select(e => new
                    {
                        e.Id,
                        e.Ad,
                        Katilimcilar = e.Kayitlar.OrderBy(k => k.KatilimciId)
                            .Select(k => k.Katilimci.Ad).ToList()
                    }).ToListAsync(cancellationToken);
                rapor = satirlar.Select(e => new RaporSatiri(e.Id, e.Ad, e.Katilimcilar)).ToList();
            }
            else
            {
                var sorgu = db.Etkinlikler.Include(e => e.Kayitlar).ThenInclude(k => k.Katilimci)
                    .AsSingleQuery().OrderBy(e => e.Id).AsQueryable();
                if (yontem == "Include + AsNoTracking")
                    sorgu = sorgu.AsNoTracking();
                var etkinlikler = await sorgu.ToListAsync(cancellationToken);
                rapor = etkinlikler.Select(e => new RaporSatiri(e.Id, e.Ad,
                    e.Kayitlar.OrderBy(k => k.KatilimciId).Select(k => k.Katilimci.Ad).ToList())).ToList();
            }

            sonuclar.Add(new Olcum(yontem, sayac.Komutlar.Count,
                db.ChangeTracker.Entries().Count(), rapor, sayac.Komutlar.ToArray()));
        }
        return sonuclar;
    }
}

KomutSayaci bu örnekte asenkron reader komutlarını sayar ve SQL metnini kaydeder. Başka komut türlerini veya senkron sorguları kapsayan genel bir sayaç değildir. ToQueryString() sorgunun SQL gösterimini inceleyebilir. Buradaki sayaç ise gerçekten çalıştırılmaya gönderilen komutları kaydeder.

Üretilen SQL’i karşılaştır

Aşağıdaki projection SQL’i, testte EF Core 10.0.12 SQLite sağlayıcısının ürettiği gerçek çıktıdır. İlişkili adları ve sonuçların eşleştirilmesi için gereken kimlikleri seçer. Include sorgusu buna ek olarak etkinliğin açıklama ve kontenjan alanlarını da getirir.

SQLite · Projection SQL
SELECT "e"."Id", "e"."Ad", "s"."Ad", "s"."EtkinlikId", "s"."KatilimciId", "s"."Id"
FROM "Etkinlikler" AS "e"
LEFT JOIN (
    SELECT "k"."Ad", "e0"."EtkinlikId", "e0"."KatilimciId", "k"."Id"
    FROM "EtkinlikKayitlari" AS "e0"
    INNER JOIN "Katilimcilar" AS "k" ON "e0"."KatilimciId" = "k"."Id"
) AS "s" ON "e"."Id" = "s"."EtkinlikId"
ORDER BY "e"."Id", "s"."KatilimciId", "s"."EtkinlikId"

İzlemeli ve izlemesiz Include bu örnekte aynı SQL’i üretti. Aralarındaki fark, sonuçların DbContext tarafından takip edilmesidir. N+1 sorgusu ise etkinlik listesinden sonra her etkinliğin katılımcıları için aynı parametreli SQL’i tekrar çalıştırdı. SQL Server sağlayıcısının SQL sözdizimi ve planı farklı olabilir.

Kendi veritabanında ölç

On dördüncü dersin migration’ları uygulanmış geliştirici SQL Server veritabanını kullan. ZIP içindeki Etkinlikler klasöründe aşağıdaki komut, dört yöntemin komut sayısını, takip edilen varlıkları, sonuçları ve çalıştırılan SQL metinlerini yazar.

Terminal · macOS ve Linux
dotnet restore
ASPNETCORE_ENVIRONMENT=Development dotnet run --no-launch-profile -- --sorgu-karsilastir

PowerShell’de önce $env:ASPNETCORE_ENVIRONMENT = "Development" çalıştır ve ön eki çıkar. Veritabanındaki etkinlik sayısı ve ilişkiler değişirse ölçülen sayılar da değişir. Karşılaştırma okuma yapar.

Test ve değerlendirme

Test her yöntemin aynı iki etkinliği ve üç katılımcıyı döndürdüğünü, komut sayılarını ve takip durumunu doğrular.

Terminal · ZIP içindeki ders klasöründen
dotnet test Etkinlikler.Tests/Etkinlikler.Tests.csproj
dotnet test Etkinlikler.Tests/Etkinlikler.Tests.csproj --filter FullyQualifiedName~SorguKarsilastirmasi --logger 'console;verbosity=detailed'

Komut sayısı tek başına hız ölçümü değildir. Veri miktarı, aktarılan satırlar, indeksler, ağ gecikmesi ve sorgu planı sonucu etkiler. Çok sayıda ilişkili kayıt JOIN sonucunda ana etkinlik verilerini tekrarlayabilir. Gerçek iş yükünde süre ve planı da ölç.

Alıştırma olarak ikinci etkinliğe katılımcı ekle ve dört yöntemin çıktılarını yeniden karşılaştır.
