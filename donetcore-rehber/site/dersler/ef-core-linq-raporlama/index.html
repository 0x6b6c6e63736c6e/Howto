EF Core ve LINQ ile doluluk raporu

Dördüncü dersteki doluluk raporunu LINQ ile yaz. EF Core’un ürettiği SQL’i, elle yazdığın T-SQL sorgusuyla karşılaştır.

.NET 10 ve EF Core 10Ders 5Yaklaşık 35 dakika
Ön koşul

Üçüncü dersteki SQL Server bağlantısı ve dördüncü dersteki doluluk raporu. Üretilen SQL’i incelemek için SQL Server bağlantısı gerekmez.

Aynı örnek veriyi hazırla

Dördüncü derste kayıtlar geçici tablolardaydı. Bu örnek, aynı iki etkinlik ve üç kayıtla çalışır. EtkinlikKayitlariniEkle migration’ı, Katilimcilar ve EtkinlikKayitlari tablolarını oluşturup örnek kayıtları ekler. Mevcut Etkinlikler tablosu ve etkinlikler korunur. Üç kayıt, üçüncü dersteki Id = 1 etkinliğine bağlanır.

Örnek ZIP’i aç, Etkinlikler klasörüne gir ve üçüncü dersteki geliştirici veritabanı bağlantısını kullan. Yeni bir ders veritabanında iki migration da uygulanır. Veritabanında sonradan eklediğin etkinlikler raporda ayrıca görünür.

Doluluk sorgusunu LINQ ile yaz

join … into eşleşmeleri gruplar. Hemen ardından gelen DefaultIfEmpty(), kaydı olmayan etkinliği de sorguya dahil eder. Grup anahtarında etkinliğin kimliği yer alır. Böylece aynı adı taşıyan etkinlikler birleşmez.

Sol birleştirmeden gelen katılımcı kimliği NULL olabilir. Bu yüzden LINQ grubunda kimliği nullable olarak alır ve yalnızca dolu kimlikleri sayarız. Sorgu önce grup anahtarını ve sayımı bir sonuç nesnesine aktarır. Kalan yer ve yüzde bu değerlerden hesaplanır. 100m, yüzdeyi ondalıklı hesaplamamızı sağlar.

Data/DolulukRaporu.cs
using Etkinlikler.Models;

namespace Etkinlikler.Data;

public static class DolulukRaporu
{
    public static IQueryable<EtkinlikDolulugu> Sorgu(EtkinlikDbContext db)
    {
        var sayim =
            from etkinlik in db.Etkinlikler
            join kayit in db.EtkinlikKayitlari on etkinlik.Id equals kayit.EtkinlikId into kayitlar
            from kayit in kayitlar.DefaultIfEmpty()
            group (int?)kayit.KatilimciId by new { etkinlik.Id, etkinlik.Ad, etkinlik.Kontenjan } into etkinlikGrubu
            select new
            {
                etkinlikGrubu.Key.Id,
                etkinlikGrubu.Key.Ad,
                etkinlikGrubu.Key.Kontenjan,
                KayitSayisi = etkinlikGrubu.Count(katilimciId => katilimciId != null)
            };

        return sayim.OrderBy(satir => satir.Id)
            .Select(satir => new EtkinlikDolulugu(
                satir.Ad,
                satir.Kontenjan,
                satir.KayitSayisi,
                satir.Kontenjan - satir.KayitSayisi,
                Math.Round(100m * satir.KayitSayisi / satir.Kontenjan, 2)));
    }
}

Sorgu bir IQueryable döndürür. SQL sorgusu, controller’daki ToListAsync çağrısında çalıştırılır. Razor view sonuçtaki yüzdeleri iki ondalık basamakla gösterir.

EF Core’un ürettiği SQL’i incele

ToQueryString() sorgunun SQL karşılığını incelemeye yarar. Örnekteki --rapor-sql seçeneği SQL Server’a bağlantı açmadan bu metni yazdırır.

Terminal
dotnet run --no-launch-profile -- --rapor-sql
EF Core 10.0.12 · ToQueryString çıktısı
SELECT [e].[Ad], [e].[Kontenjan], COUNT(CASE
    WHEN [e0].[KatilimciId] IS NOT NULL THEN 1
END), [e].[Kontenjan] - COUNT(CASE
    WHEN [e0].[KatilimciId] IS NOT NULL THEN 1
END), ROUND((100.0 * CAST(COUNT(CASE
    WHEN [e0].[KatilimciId] IS NOT NULL THEN 1
END) AS decimal(18,2))) / CAST([e].[Kontenjan] AS decimal(18,2)), 2)
FROM [Etkinlikler] AS [e]
LEFT JOIN [EtkinlikKayitlari] AS [e0] ON [e].[Id] = [e0].[EtkinlikId]
GROUP BY [e].[Id], [e].[Ad], [e].[Kontenjan]
ORDER BY [e].[Id]

Dördüncü dersteki T-SQL ile karşılaştır

Ders 4 · Elle yazılan T-SQL
SELECT
    e.Ad AS Etkinlik,
    e.Kontenjan,
    COUNT(r.KatilimciId) AS KayitSayisi,
    e.Kontenjan - COUNT(r.KatilimciId) AS KalanYer,
    CAST(100.0 * COUNT(r.KatilimciId) / e.Kontenjan AS decimal(5, 2)) AS DolulukYuzdesi
FROM dbo.Etkinlikler AS e
LEFT JOIN #AtolyeKayitlar AS r ON e.Id = r.EtkinlikId
GROUP BY e.Id, e.Ad, e.Kontenjan
ORDER BY e.Id;

Her iki sayım da eşleşmeyen satırı atlar. Yüzdeyi iki basamağa yuvarlarlar. Elle yazılan sorgu decimal(5, 2) türünü döndürür. EF Core sorgusundaki ROUND değeri yuvarlar ve görünüm iki basamaklı biçimi uygular. Aynı veriler üzerinde doğrudan karşılaştırmak için elle yazılan sorgudaki #AtolyeKayitlar adını dbo.EtkinlikKayitlari ile değiştir.
