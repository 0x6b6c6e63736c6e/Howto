MVC 5’ten ASP.NET Core’a geçiş

Bir etkinlik listeleme ekranını ASP.NET Core MVC’ye taşı. Bu derste isteğin route üzerinden controller’a, oradan Razor view’a nasıl ulaştığını göreceksin.

.NET 10BaşlangıçYaklaşık 20 dakika
Ön koşul

.NET 10 SDK ve bir kod editörü. Örnekte iki etkinlik bellekte tutulur. SQL Server bağlantısını EF Core bölümünde ekleyeceğiz.

Projeyi oluştur

Terminalde aşağıdaki komutları çalıştır. MVC şablonu örnek ekranlar da üretir. Bu derste kendi controller ve view dosyanı ekleyeceksin.

Terminal
dotnet --list-sdks
dotnet new mvc -n Etkinlikler -f net10.0
cd Etkinlikler

Servisleri ve route’u tanımla

Program.cs dosyasını aşağıdakiyle değiştir. AddControllersWithViews MVC servislerini kaydeder. MapControllerRoute ise kök adresi EtkinliklerController.Index metoduna yönlendirir. Bu örnek şablonun ek sayfaları yerine etkinlik listesiyle başlar.

Program.cs
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllersWithViews();

var app = builder.Build();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Etkinlikler}/{action=Index}/{id?}");

app.Run();

Controller’ı taşı

MVC 5’te aynı action şu şekilde yazılabilir.

MVC 5 · EtkinliklerController.cs
using System.Web.Mvc;

public class EtkinliklerController : Controller
{
    public ActionResult Index()
    {
        var etkinlikler = new[] {
            "Web Geliştirme Atölyesi", "SQL Server Semineri"
        };
        return View(etkinlikler);
    }
}

Core projesine aşağıdaki dosyayı ekle. View(etkinlikler) model olarak etkinlik dizisini gönderir. MVC, adlandırma kuralıyla Views/Etkinlikler/Index.cshtml dosyasını bulur.

Controllers/EtkinliklerController.cs
using Microsoft.AspNetCore.Mvc;

namespace Etkinlikler.Controllers;

public class EtkinliklerController : Controller
{
    public IActionResult Index()
    {
        string[] etkinlikler = ["Web Geliştirme Atölyesi", "SQL Server Semineri"];
        return View(etkinlikler);
    }
}

Razor view’ı ekle

Aşağıdaki dosyayı ekle. foreach her etkinliği ayrı bir liste öğesi olarak gösterir. Layout = null bu sayfanın şablondaki ortak layout’tan bağımsız olarak kendi HTML belgesini oluşturmasını sağlar.

Views/Etkinlikler/Index.cshtml
@model IReadOnlyList<string>
@{ Layout = null; }
<!doctype html>
<html lang="tr">
<head>
    <meta charset="utf-8" />
    <title>Etkinlikler</title>
</head>
<body>
    <h1>Etkinlikler</h1>
    <ul>
        @foreach (var etkinlik in Model)
        {
            <li>@etkinlik</li>
        }
    </ul>
</body>
</html>

Çalıştır ve doğrula

Terminal
dotnet run --no-launch-profile --urls http://localhost:5080

Tarayıcıda http://localhost:5080/ adresini aç. Etkinlikler başlığının altında Web Geliştirme Atölyesi ve SQL Server Semineri görünmeli. /Etkinlikler/Index adresi de aynı ekranı açar.

Alıştırma

Listeye bir etkinlik daha ekle ve ekranı yenile. Sonra varsayılan route ayarını incele ve /Etkinlikler adresinin neden aynı action’a ulaştığını açıkla.
