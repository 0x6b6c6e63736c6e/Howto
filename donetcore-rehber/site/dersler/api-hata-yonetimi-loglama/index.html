API hata yönetimi ve loglama

Hata yanıtlarını Problem Details ile düzenle, beklenmeyen hataları yakala ve yapılandırılmış loglarla izle.

Problem Details ve hata yanıtları

Problem Details, HTTP hata yanıtları için ortak alanlar sağlar. status, title ve gerektiğinde detail istemcinin hatayı anlamasına yardımcı olur. Bu örnekte istekKimligi, yanıtla sunucu kaydını ilişkilendirir.

Geçersiz model 400 ve alan hatalarıyla döner. Bulunamayan etkinlik 404, kontenjan çatışması 409 döndürür. Beklenmeyen hata 500 döndürür. JWT doğrulamasında 401 ve 403 yanıtları korunur.

Beklenmeyen hataları yakala

IExceptionHandler beklenmeyen hatayı sunucuda Error seviyesinde kaydeder ve istemciye genel bir 500 yanıtı verir. Hata ayrıntıları sunucu logunda kalır. Bu örnekte işleyici hem MVC hem API isteklerindeki işlenmemiş hataları kapsar.

Hatalar/ApiExceptionHandler.cs
using Microsoft.AspNetCore.Diagnostics;

namespace Etkinlikler.Hatalar;

public sealed class ApiExceptionHandler(ILogger<ApiExceptionHandler> logger) : IExceptionHandler
{
    public async ValueTask<bool> TryHandleAsync(
        HttpContext context, Exception exception, CancellationToken cancellationToken)
    {
        logger.LogError(exception, "İşlenmeyen istek hatası. İstekKimliği: {IstekKimligi}", context.TraceIdentifier);
        context.Response.StatusCode = StatusCodes.Status500InternalServerError;
        await Results.Problem(
            statusCode: StatusCodes.Status500InternalServerError,
            title: "Sunucu hatası",
            detail: "İstek işlenirken beklenmeyen bir hata oluştu.",
            extensions: new Dictionary<string, object?> { ["istekKimligi"] = context.TraceIdentifier }
        ).ExecuteAsync(context);
        return true;
    }
}

AddProblemDetails varsayılan Problem Details üretimini kaydeder. UseStatusCodePages yalnızca API yolunda boş hata yanıtlarını gövdeyle tamamlar. Middleware sırası önemlidir. İstisna işleyicisi, kimlik doğrulama ve endpoint işlemlerinden önce gelir.

Program.cs · ilgili satırlar
builder.Services.AddExceptionHandler<ApiExceptionHandler>();
builder.Services.AddProblemDetails(options =>
    options.CustomizeProblemDetails = context =>
        context.ProblemDetails.Extensions["istekKimligi"] = context.HttpContext.TraceIdentifier);

// app oluşturulduktan sonra, authentication ve authorization öncesinde
app.UseExceptionHandler();
app.UseWhen(context => context.Request.Path.StartsWithSegments("/api"), api =>
{
    api.UseStatusCodePages();
});

400 doğrulama yanıtındaki alan hataları ValidationProblemDetails içindedir. İstek kimliği için bu yanıtta varsayılan traceId, diğer örnek yanıtlarda istekKimligi alanını kullan.

Yapılandırılmış loglama

ILogger<T> sınıf kategorisiyle log üretir. Başarılı ekleme, güncelleme ve silme Information, bulunamayan etkinlik ve kontenjan çatışması Warning seviyesinde kaydedilir. Yer tutucular etkinlik kimliğini ayrı bir değer olarak taşır.

EtkinliklerApiController.cs
using Etkinlikler.Data;
using Etkinlikler.Models;
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Controllers.Api;

[ApiController]
[Route("api/etkinlikler")]
public class EtkinliklerApiController(EtkinlikDbContext db, ILogger<EtkinliklerApiController> logger) : ControllerBase
{
    [HttpGet]
    public async Task<IActionResult> Listele([FromQuery] EtkinlikSorgusu istek, CancellationToken cancellationToken)
    {
        var sorgu = db.Etkinlikler.AsNoTracking().AsQueryable();
        if (!string.IsNullOrWhiteSpace(istek.Arama))
        {
            var arama = istek.Arama.Trim();
            sorgu = sorgu.Where(e => e.Ad.Contains(arama));
        }
        if (istek.EnAzKontenjan.HasValue)
            sorgu = sorgu.Where(e => e.Kontenjan >= istek.EnAzKontenjan.Value);

        var toplam = await sorgu.CountAsync(cancellationToken);
        var azalan = istek.Yon == "azalan";
        sorgu = istek.Sirala switch
        {
            "ad" when azalan => sorgu.OrderByDescending(e => e.Ad).ThenBy(e => e.Id),
            "ad" => sorgu.OrderBy(e => e.Ad).ThenBy(e => e.Id),
            "kontenjan" when azalan => sorgu.OrderByDescending(e => e.Kontenjan).ThenBy(e => e.Id),
            "kontenjan" => sorgu.OrderBy(e => e.Kontenjan).ThenBy(e => e.Id),
            _ when azalan => sorgu.OrderByDescending(e => e.Id),
            _ => sorgu.OrderBy(e => e.Id)
        };

        var kayitlar = await sorgu.Skip((istek.Sayfa - 1) * istek.SayfaBoyutu)
            .Take(istek.SayfaBoyutu).ToListAsync(cancellationToken);
        return Ok(new { istek.Sayfa, istek.SayfaBoyutu, toplamKayit = toplam, kayitlar });
    }

    [HttpGet("{id:int}")]
    public async Task<ActionResult<Etkinlik>> Getir(int id, CancellationToken cancellationToken)
    {
        var etkinlik = await db.Etkinlikler.AsNoTracking()
            .SingleOrDefaultAsync(e => e.Id == id, cancellationToken);
        if (etkinlik is null)
        {
            logger.LogWarning("Etkinlik bulunamadı. EtkinlikId: {EtkinlikId}, İstekKimliği: {IstekKimligi}", id, HttpContext.TraceIdentifier);
            return NotFound();
        }
        return Ok(etkinlik);
    }

    [Authorize(AuthenticationSchemes = JwtBearerDefaults.AuthenticationScheme, Roles = "Yonetici")]
    [HttpPost]
    public async Task<ActionResult<Etkinlik>> Ekle(
        [FromBody] EtkinlikFormu form, CancellationToken cancellationToken)
    {
        var etkinlik = new Etkinlik { Ad = form.Ad!, Kontenjan = form.Kontenjan!.Value };
        db.Etkinlikler.Add(etkinlik);
        await db.SaveChangesAsync(cancellationToken);
        logger.LogInformation("Etkinlik oluşturuldu. EtkinlikId: {EtkinlikId}", etkinlik.Id);
        return CreatedAtAction(nameof(Getir), new { id = etkinlik.Id }, etkinlik);
    }

    [Authorize(AuthenticationSchemes = JwtBearerDefaults.AuthenticationScheme, Roles = "Yonetici")]
    [HttpPut("{id:int}")]
    public async Task<IActionResult> Guncelle(
        int id, [FromBody] EtkinlikFormu form, CancellationToken cancellationToken)
    {
        await using var transaction = await db.Database.BeginTransactionAsync(cancellationToken);
        var kilitlenen = await db.Etkinlikler.Where(e => e.Id == id)
            .ExecuteUpdateAsync(set => set.SetProperty(e => e.Kontenjan, e => e.Kontenjan), cancellationToken);
        if (kilitlenen == 0)
            return NotFound();

        var kayitSayisi = await db.EtkinlikKayitlari.CountAsync(k => k.EtkinlikId == id, cancellationToken);
        if (form.Kontenjan!.Value < kayitSayisi)
        {
            logger.LogWarning("Kontenjan güncellemesi reddedildi. EtkinlikId: {EtkinlikId}, KayitSayisi: {KayitSayisi}", id, kayitSayisi);
            return Problem(
                statusCode: StatusCodes.Status409Conflict,
                title: "Kontenjan yetersiz",
                detail: "Kontenjan mevcut kayıt sayısından az olamaz.",
                extensions: new Dictionary<string, object?> { ["kayitSayisi"] = kayitSayisi, ["istekKimligi"] = HttpContext.TraceIdentifier });
        }

        var etkinlik = await db.Etkinlikler.SingleAsync(e => e.Id == id, cancellationToken);
        etkinlik.Ad = form.Ad!;
        etkinlik.Kontenjan = form.Kontenjan.Value;
        await db.SaveChangesAsync(cancellationToken);
        await transaction.CommitAsync(cancellationToken);
        logger.LogInformation("Etkinlik güncellendi. EtkinlikId: {EtkinlikId}", id);
        return NoContent();
    }

    [Authorize(AuthenticationSchemes = JwtBearerDefaults.AuthenticationScheme, Roles = "Yonetici")]
    [HttpDelete("{id:int}")]
    public async Task<IActionResult> Sil(int id, CancellationToken cancellationToken)
    {
        await using var transaction = await db.Database.BeginTransactionAsync(cancellationToken);
        var kilitlenen = await db.Etkinlikler.Where(e => e.Id == id)
            .ExecuteUpdateAsync(set => set.SetProperty(e => e.Kontenjan, e => e.Kontenjan), cancellationToken);
        if (kilitlenen == 0)
            return NotFound();

        var etkinlik = await db.Etkinlikler.SingleAsync(e => e.Id == id, cancellationToken);
        db.Etkinlikler.Remove(etkinlik);
        await db.SaveChangesAsync(cancellationToken);
        await transaction.CommitAsync(cancellationToken);
        logger.LogInformation("Etkinlik silindi. EtkinlikId: {EtkinlikId}", id);
        return NoContent();
    }
}

Parola, JWT, Authorization başlığı veya isteğin tamamını loga ekleme. Hata günlükleri sunucu ve veritabanı ayrıntıları içerebileceğinden erişimlerini ve saklama süresini ortamına göre yönet.

Yanıtları incele

Örnek projeyi on ikinci dersteki bağlantı ve JWT ayarlarıyla çalıştır. Listede geçersiz sayfa ve olmayan bir etkinlik isteyerek yanıtları incele.

Terminal · ZIP içindeki ders klasöründen
ASPNETCORE_ENVIRONMENT=Development dotnet run --project Etkinlikler --no-launch-profile --urls http://localhost:5090
# Başka bir terminalde
curl -i 'http://localhost:5090/api/etkinlikler?sayfa=0'
curl -i 'http://localhost:5090/api/etkinlikler/999999'

404 yanıtındaki istekKimligi ile sunucu konsolundaki uyarıyı incele. 500 örneği için test projesi bağlantısı kapatılmış geçici veritabanı kullanır. Böylece istemciye verilen yanıt ve log davranışı geliştirme verileri üzerinde denenir.

Test ve alıştırma

Testler 400, 404 ve 500 durumlarını, Problem Details içerik türünü, hata yanıtındaki istek kimliğini ve sunucu hata ayrıntılarının yanıta taşınmadığını kontrol eder. Mevcut JWT testleri de çalışır.

Terminal
dotnet test Etkinlikler.Tests/Etkinlikler.Tests.csproj

Alıştırma olarak bulunamayan etkinlik isteğini tekrarla. Logdaki etkinlik kimliğini ve yanıttaki istek kimliğini gözlemle. Ardından kontenjan çatışması üretip 409 yanıtını incele.
