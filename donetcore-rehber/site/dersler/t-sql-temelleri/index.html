T-SQL temelleri

Etkinlik veritabanında SELECT ile listele, JOIN ile katılımcıları eşleştir ve GROUP BY ile doluluk raporu çıkar.

SQL ServerDers 4Yaklaşık 30 dakika
Ön koşul

Üçüncü dersteki ilk migration uygulanmış olmalı. Beklenen sonuçlar iki başlangıç etkinliğini temel alır. Uygulamadan sonradan eklediğin etkinlikler, koşulları sağlıyorsa raporlara ek satır olarak gelir.

Rapor betiğini indir

Örnek veriyi hazırla

SQL sorgu aracında üçüncü derste oluşturduğun DotNetAtolyeEtkinlikler veritabanını seç. Aşağıdaki betik dbo.Etkinlikler tablosundaki iki başlangıç etkinliğini kullanır. #AtolyeKatilimcilar ve #AtolyeKayitlar bağlantıya özel geçici tablolardır. Betiği ve raporları aynı sorgu oturumunda çalıştır. Betiği yeniden çalıştırmak yalnızca bu iki geçici tabloyu baştan kurar.

Her kayıt bir etkinlik kimliğiyle bir katılımcı kimliğini eşleştirir. Bileşik birincil anahtar aynı katılımcının aynı etkinlikte iki kez sayılmasını önler. Örnekte üç katılımcı Web Geliştirme Atölyesi’ne kayıtlı. SQL Server Semineri’nin kaydı yok.

T-SQL · Geçici örnek tablolar
IF OBJECT_ID(N'dbo.Etkinlikler', N'U') IS NULL
    THROW 50001, N'Ders 3 migration adımını tamamlayın ve doğru veritabanını seçin.', 1;

IF NOT EXISTS (SELECT 1 FROM dbo.Etkinlikler WHERE Id = 1)
    OR NOT EXISTS (SELECT 1 FROM dbo.Etkinlikler WHERE Id = 2)
    THROW 50002, N'Rapor örnekleri Ders 3 başlangıç etkinliklerini gerektirir.', 1;

DROP TABLE IF EXISTS #AtolyeKayitlar;
DROP TABLE IF EXISTS #AtolyeKatilimcilar;

CREATE TABLE #AtolyeKatilimcilar (
    Id int NOT NULL PRIMARY KEY,
    Ad nvarchar(80) NOT NULL
);

CREATE TABLE #AtolyeKayitlar (
    EtkinlikId int NOT NULL,
    KatilimciId int NOT NULL,
    PRIMARY KEY (EtkinlikId, KatilimciId)
);

SELECT ile etkinlikleri filtrele

SELECT sonuçta gösterilecek sütunları, FROM kaynak tabloyu, WHERE satır koşulunu belirler. ORDER BY kontenjanı büyükten küçüğe sıralar. Kontenjanlar eşitse etkinlik kimliği sıralamayı belirler.

Rapor · 30 ve üzeri kontenjan
-- SELECT: 30 ve üzeri kontenjanı olan etkinlikler
SELECT e.Id, e.Ad, e.Kontenjan
FROM dbo.Etkinlikler AS e
WHERE e.Kontenjan >= 30
ORDER BY e.Kontenjan DESC, e.Id;

INNER JOIN ile katılımcıları listele

Her kayıttaki EtkinlikId etkinliğe, KatilimciId katılımcıya bağlanır. ON koşulları hangi satırların eşleşeceğini belirler. INNER JOIN iki tarafta da eşleşme aradığı için kaydı olmayan seminer bu listede görünmez.

Rapor · Katılımcı listesi
-- INNER JOIN: Etkinliğe kayıtlı katılımcılar
SELECT e.Ad AS Etkinlik, k.Ad AS Katilimci
FROM #AtolyeKayitlar AS r
INNER JOIN dbo.Etkinlikler AS e ON e.Id = r.EtkinlikId
INNER JOIN #AtolyeKatilimcilar AS k ON k.Id = r.KatilimciId
ORDER BY e.Id, k.Id;

LEFT JOIN ve GROUP BY ile doluluk raporu

LEFT JOIN kaydı olmayan etkinlikleri de korur. GROUP BY her etkinliği tek satıra toplar. Kimliği de gruba eklediğimiz için aynı ada ve kontenjana sahip iki etkinlik ayrı sayılır.

COUNT(r.KatilimciId) yalnızca dolu kimlikleri sayar. Burada COUNT(*) kullanmak kaydı olmayan etkinliği de bir kayıt varmış gibi sayar. 100.0 ondalıklı bölme sağlar. Kontenjan kısıtı paydanın sıfır olmasını önler.

Rapor · Etkinlik doluluğu ve kalan yer
-- LEFT JOIN ve GROUP BY: Etkinlik başına doluluk
SELECT
    e.Ad AS Etkinlik,
    e.Kontenjan,
    COUNT(r.KatilimciId) AS KayitSayisi,
    e.Kontenjan - COUNT(r.KatilimciId) AS KalanYer,
    CAST(100.0 * COUNT(r.KatilimciId) / e.Kontenjan AS decimal(5, 2)) AS DolulukYuzdesi
FROM dbo.Etkinlikler AS e
LEFT JOIN #AtolyeKayitlar AS r ON e.Id = r.EtkinlikId
GROUP BY e.Id, e.Ad, e.Kontenjan
ORDER BY e.Id;

HAVING ile grupları filtrele

WHERE gruplamadan önce satırları filtreler. HAVING ise gruplama tamamlandıktan sonra özet değerlere koşul uygular. Bu örneğin sonucu üç kaydı olan Web Geliştirme Atölyesi’dir.

Rapor · En az iki kaydı olan etkinlikler
-- HAVING: En az iki kaydı olan etkinlikler
SELECT e.Ad AS Etkinlik, COUNT(r.KatilimciId) AS KayitSayisi
FROM dbo.Etkinlikler AS e
LEFT JOIN #AtolyeKayitlar AS r ON e.Id = r.EtkinlikId
GROUP BY e.Id, e.Ad
HAVING COUNT(r.KatilimciId) >= 2
ORDER BY KayitSayisi DESC, e.Id;

Alıştırma

Doluluk raporunu yalnızca kaydı olmayan etkinlikleri gösterecek şekilde değiştir. Ardından #AtolyeKayitlar tablosuna (2, 1) kaydını ekleyip doluluk raporunu yeniden çalıştır. Seminer için bir kayıt, 39 kalan yer ve %2,50 doluluk görmelisin.
