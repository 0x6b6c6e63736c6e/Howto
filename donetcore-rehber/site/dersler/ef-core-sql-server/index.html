EF Core ile SQL Server’a bağlan

Etkinlik listesini bellekte tutan servisi SQL Server’a taşı. DbContext’i tanımla, ilk migration’ı uygula ve formdan eklenen kayıtları kalıcı olarak sakla.

.NET 10 ve EF Core 10Ders 3Yaklaşık 40 dakika
Ön koşul

.NET 10 SDK, erişebildiğin bir SQL Server ve ikinci dersteki etkinlik formu. Apple Silicon kullanıyorsan desteklenen bir bilgisayarda veya uzak sunucuda çalışan SQL Server’a bağlanabilirsin.

Projeyi ve paketleri hazırla

Örnek ZIP’i açıp Etkinlikler dizinine gir. Proje, SQL Server sağlayıcısını ve migration üretmek için Design paketini içeriyor. Aynı sürümdeki dotnet-ef aracı proje manifestinde tanımlı.

Terminal · İndirilen örneği hazırla
dotnet restore
dotnet tool restore

İkinci dersteki projeyi kendin güncelliyorsan önce projenin bir kopyasını al. Yeni kopyada bellek içi EtkinlikListesi servisini, kaydını ve eski Etkinlik tanımını kaldır. Paket referanslarını ve UserSecretsId ayarını aşağıdaki dosyadan, araç manifestini de örnekten al. İki Razor view ile EtkinlikFormu aynı şekilde kullanılır.

Etkinlikler.csproj
<Project Sdk="Microsoft.NET.Sdk.Web">
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
    <UserSecretsId>DotNetAtolye-Etkinlikler-Ders03</UserSecretsId>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="Microsoft.EntityFrameworkCore.SqlServer" Version="10.0.12" />
    <PackageReference Include="Microsoft.EntityFrameworkCore.Design" Version="10.0.12">
      <PrivateAssets>all</PrivateAssets>
    </PackageReference>
  </ItemGroup>
</Project>

Etkinlik modelini ve DbContext’i yaz

EtkinlikFormu kullanıcı girdisini doğrular. Etkinlik veritabanındaki satırı temsil eder. EF Core, Id özelliğini birincil anahtar olarak tanır. SQL Server sağlayıcısı bu tamsayı anahtarı için otomatik değer üretir.

Models/Etkinlik.cs
namespace Etkinlikler.Models;

public sealed class Etkinlik
{
    public int Id { get; set; }
    public string Ad { get; set; } = string.Empty;
    public int Kontenjan { get; set; }
}

DbContext sorguları çalıştırır ve kayda gönderilecek değişiklikleri izler. DbSet<Etkinlik> etkinlikleri sorgulama ve yeni kayıt ekleme giriş noktasıdır. Aşağıdaki yapılandırma, ad sütununu en fazla 80 karakterle sınırlar ve kontenjan aralığını veritabanında da zorunlu kılar. İlk migration önceki dersten tanıdığımız iki örnek satırı ekler.

Data/EtkinlikDbContext.cs
using Etkinlikler.Models;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Data;

public sealed class EtkinlikDbContext(DbContextOptions<EtkinlikDbContext> options)
    : DbContext(options)
{
    public DbSet<Etkinlik> Etkinlikler => Set<Etkinlik>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        var etkinlik = modelBuilder.Entity<Etkinlik>();

        etkinlik.ToTable("Etkinlikler", table =>
            table.HasCheckConstraint("CK_Etkinlikler_Kontenjan", "[Kontenjan] BETWEEN 1 AND 500"));

        etkinlik.Property(item => item.Ad).HasMaxLength(80).IsRequired();

        etkinlik.HasData(
            new Etkinlik { Id = 1, Ad = "Web Geliştirme Atölyesi", Kontenjan = 25 },
            new Etkinlik { Id = 2, Ad = "SQL Server Semineri", Kontenjan = 40 });
    }
}

SQL Server bağlantısını ayarla

SQL Server’da bu ders için ayrı bir DotNetAtolyeEtkinlikler veritabanı kullan. Migration’ı çalıştıran hesabın şema oluşturma yetkisi olmalı. Veritabanını EF Core’un oluşturmasını bekliyorsan hesabın veritabanı oluşturma yetkisi de gerekir.

Aşağıdaki komuttaki sunucu, kullanıcı ve parola alanlarını kendi geliştirme ortamına göre doldur. Uzak bir SQL Server kullanıyorsan sunucu adresini değiştir. TrustServerCertificate=True yalnızca kendinden imzalı sertifika kullanılan geliştirme sunucusu içindir. Güvenilen sertifikası olan sunucuda bu seçeneği kaldır.

Terminal · Geliştirme bağlantısı
dotnet user-secrets set "ConnectionStrings:EtkinlikDb" "Server=localhost,1433;Database=DotNetAtolyeEtkinlikler;User Id=KULLANICI;Password=PAROLA;Encrypt=True;TrustServerCertificate=True"

user-secrets ayarı proje dosyalarının dışında tutar. ASP.NET Core bunu Development ortamında yükler. AddDbContext varsayılan olarak her HTTP isteği için ayrı bir context sağlar. UseSqlServer kullanılacak veritabanı sağlayıcısını seçer.

Program.cs
using Etkinlikler.Data;
using Microsoft.EntityFrameworkCore;

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllersWithViews();

var connection = builder.Configuration.GetConnectionString("EtkinlikDb")
    ?? throw new InvalidOperationException("ConnectionStrings:EtkinlikDb ayarını girin.");

builder.Services.AddDbContext<EtkinlikDbContext>(options =>
    options.UseSqlServer(connection));

var app = builder.Build();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Etkinlikler}/{action=Index}/{id?}");

app.Run();

Listeyi oku ve formu kaydet

ToListAsync sorguyu SQL Server’da çalıştırır. Salt okunur liste için AsNoTracking kullanılır. Geçerli form gönderiminde Add yeni kaydı context’e ekler. SaveChangesAsync değişikliği SQL Server’a gönderir. Form hataları önceki dersteki gibi kullanıcıya gösterilir.

Controllers/EtkinliklerController.cs
using Etkinlikler.Data;
using Etkinlikler.Models;
using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Controllers;

public class EtkinliklerController(EtkinlikDbContext db) : Controller
{
    [HttpGet]
    public async Task<IActionResult> Index(CancellationToken cancellationToken)
    {
        var etkinlikler = await db.Etkinlikler
            .AsNoTracking()
            .OrderBy(etkinlik => etkinlik.Id)
            .ToListAsync(cancellationToken);

        return View(etkinlikler);
    }

    [HttpGet]
    public IActionResult Ekle() => View(new EtkinlikFormu());

    [HttpPost]
    [ValidateAntiForgeryToken]
    public async Task<IActionResult> Ekle(EtkinlikFormu form, CancellationToken cancellationToken)
    {
        if (!ModelState.IsValid)
        {
            return View(form);
        }

        db.Etkinlikler.Add(new Etkinlik
        {
            Ad = form.Ad!,
            Kontenjan = form.Kontenjan!.Value
        });

        await db.SaveChangesAsync(cancellationToken);
        return RedirectToAction(nameof(Index));
    }
}

İlk migration’ı oluştur ve uygula

Kendi kopyandan ilerliyorsan ilk migration’ı aşağıdaki komutla üret. ZIP’i indirdiysen IlkKurulum zaten Migrations klasöründe bulunur ve doğrudan sonraki adıma geçebilirsin.

Terminal · macOS ve Linux
ASPNETCORE_ENVIRONMENT=Development dotnet ef migrations add IlkKurulum

Windows PowerShell kullanıyorsan önce $env:ASPNETCORE_ENVIRONMENT = "Development" çalıştır ve bu bölümdeki komutları ASPNETCORE_ENVIRONMENT=Development ön eki olmadan gir.

Migration’daki Up metodu tabloyu, kısıtları ve örnek kayıtları oluşturur. Down metodu bu değişikliği geri alır. ModelSnapshot dosyası bir sonraki migration için modelin karşılaştırma temelidir.

Terminal · SQL’i incele ve migration’ı uygula
ASPNETCORE_ENVIRONMENT=Development dotnet ef migrations script --idempotent -o IlkKurulum.sql
ASPNETCORE_ENVIRONMENT=Development dotnet ef database update

migrations script inceleyebileceğin bir SQL dosyası üretir. database update değişiklikleri uygular ve uygulanan migration’ı __EFMigrationsHistory tablosuna kaydeder.

Çalıştır ve kalıcılığı kontrol et

Terminal · Uygulamayı başlat
ASPNETCORE_ENVIRONMENT=Development dotnet run --no-launch-profile --urls http://localhost:5082

Tarayıcıda http://localhost:5082/ adresini aç. İlk iki etkinliği görmelisin. Formdan EF Core Atölyesi adında, 30 kişilik bir etkinlik ekle. Uygulamayı durdurup yeniden başlattığında yeni etkinlik listede kalmalı.

T-SQL · Kayıtları ve migration geçmişini kontrol et
SELECT Id, Ad, Kontenjan
FROM dbo.Etkinlikler
ORDER BY Id;

SELECT MigrationId
FROM dbo.__EFMigrationsHistory;

Alıştırma

Etkinlik modeline isteğe bağlı bir açıklama alanı ekle ve uzunluğunu 150 karakterle sınırla. AciklamaEkle adında yeni bir migration üret. Önce üretilen AddColumn işlemini incele, sonra migration’ı geliştirici veritabanına uygula ve mevcut üç kaydın yerinde kaldığını kontrol et.
