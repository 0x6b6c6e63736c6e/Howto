JWT ve rol tabanlı yetkilendirme

Identity ile eğitim amaçlı token üret, Bearer doğrulamasını ve yönetici rolünü API’de uygula.

.NET 10Ders 12Yaklaşık 45 dakika
Ön koşul

On birinci ders, Identity yönetici hesabı ve SQL Server bağlantısı.

Örnek projeyi indir

Token akışı

İstemci geliştirme ortamında e-posta ve parolayı POST /api/token adresine gönderir. Identity parolayı doğrular. Örnek, kullanıcının rollerini içeren 15 dakikalık bir JWT üretir. İstemci sonraki istekte Authorization: Bearer <token> başlığını gönderir. API imzayı, veren kurumu, hedefi ve süreyi doğrular.

Bu token üreticisi eğitim ve yerel test içindir. Uygulama yalnızca Development ortamında token üretir. Gerçek yayın için OAuth 2.0 ve OpenID Connect destekleyen bir kimlik sağlayıcısı kullan.

JWT doğrulamasını yapılandır

JwtBearer paketi eklenir. Identity’nin MVC çerez şeması korunur ve API işlemleri açıkça Bearer şemasını seçer. İmza anahtarını User Secrets üzerinden sağla. Örnekte anahtar en az 32 bayt olmalıdır. Issuer ve audience değerleri token üretimiyle doğrulama sırasında aynı olmalıdır.

Program.cs
using Etkinlikler.Data;
using System.Text;
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.IdentityModel.Tokens;
using Microsoft.AspNetCore.Identity;
using Microsoft.EntityFrameworkCore;

if (args is ["--rapor-sql"])
{
    // SQL üretmek için sağlayıcı gerekir. Bu bağlantı açılmaz.
    var options = new DbContextOptionsBuilder<EtkinlikDbContext>()
        .UseSqlServer("Server=localhost;Database=DotNetAtolyeEtkinlikler;Integrated Security=True;Encrypt=True")
        .Options;
    using var db = new EtkinlikDbContext(options);
    Console.WriteLine(DolulukRaporu.Sorgu(db).ToQueryString());
    return;
}

var yoneticiOlustur = args is ["--yonetici-olustur"];
var kayitDeneyi = args is ["--kayit-deneyi"];
var builder = WebApplication.CreateBuilder(kayitDeneyi || yoneticiOlustur ? [] : args);
builder.Services.AddControllersWithViews();
builder.Services.AddAntiforgery(options => options.HeaderName = "X-CSRF-TOKEN");
builder.Services.AddScoped<EtkinlikKayitServisi>();
builder.Services.AddIdentity<IdentityUser, IdentityRole>()
    .AddEntityFrameworkStores<EtkinlikDbContext>()
    .AddDefaultTokenProviders();
builder.Services.AddAuthentication().AddJwtBearer();
builder.Services.AddOptions<JwtBearerOptions>(JwtBearerDefaults.AuthenticationScheme)
    .Configure<IConfiguration>((options, config) =>
    {
        var key = config["Jwt:Key"] ?? throw new InvalidOperationException("Jwt:Key ayarını girin.");
        if (Encoding.UTF8.GetByteCount(key) < 32)
            throw new InvalidOperationException("Jwt:Key en az 32 bayt olmalı.");
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidIssuer = config["Jwt:Issuer"] ?? throw new InvalidOperationException("Jwt:Issuer ayarını girin."),
            ValidateAudience = true,
            ValidAudience = config["Jwt:Audience"] ?? throw new InvalidOperationException("Jwt:Audience ayarını girin."),
            ValidateLifetime = true,
            ClockSkew = TimeSpan.Zero,
            ValidateIssuerSigningKey = true,
            IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(key)),
            ValidAlgorithms = [SecurityAlgorithms.HmacSha256]
        };
    });

builder.Services.ConfigureApplicationCookie(options =>
{
    options.LoginPath = "/Hesap/Giris";
    options.AccessDeniedPath = "/Hesap/ErisimEngellendi";
});

builder.Services.AddDbContext<EtkinlikDbContext>((services, options) =>
{
    var configuration = services.GetRequiredService<IConfiguration>();
    var connection = configuration.GetConnectionString("EtkinlikDb")
        ?? throw new InvalidOperationException("ConnectionStrings:EtkinlikDb ayarını girin.");
    options.UseSqlServer(connection);
});

await using var app = builder.Build();

if (yoneticiOlustur)
{
    await YoneticiKurulumu.CalistirAsync(app.Services, builder.Configuration);
    return;
}

if (kayitDeneyi)
{
    using var timeout = new CancellationTokenSource(TimeSpan.FromSeconds(30));
    await KayitDeneyi.CalistirAsync(app.Services, timeout.Token);
    return;
}

app.UseAuthentication();
app.UseAuthorization();

app.MapControllers();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Etkinlikler}/{action=Index}/{id?}");

await app.RunAsync();

public partial class Program { }

Identity ile token oluştur

CheckPasswordSignInAsync parola ve hesap kilidi kurallarını uygular. Rolleri Identity’den alıp token’a ekleriz. Yanıtta token ve bitiş zamanı bulunur. Token hassas bir kimlik bilgisidir. İstekleri HTTPS üzerinden gönder ve değeri kayıt dosyalarına yazdırma.

Controllers/Api/TokenController.cs
using System.ComponentModel.DataAnnotations;
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using System.Text;
using Microsoft.AspNetCore.Identity;
using Microsoft.AspNetCore.Mvc;
using Microsoft.IdentityModel.Tokens;

namespace Etkinlikler.Controllers.Api;

public sealed class TokenIstegi
{
    [Required, EmailAddress]
    public string? Eposta { get; set; }

    [Required]
    public string? Parola { get; set; }
}

[ApiController]
[Route("api/token")]
public class TokenController(
    IWebHostEnvironment environment,
    IConfiguration config,
    UserManager<IdentityUser> users,
    SignInManager<IdentityUser> signIn) : ControllerBase
{
    [HttpPost]
    public async Task<IActionResult> Olustur(TokenIstegi istek)
    {
        if (!environment.IsDevelopment())
            return NotFound();

        var user = await users.FindByEmailAsync(istek.Eposta!);
        if (user is null)
            return Unauthorized();

        var sonuc = await signIn.CheckPasswordSignInAsync(user, istek.Parola!, lockoutOnFailure: true);
        if (!sonuc.Succeeded)
            return Unauthorized();

        var key = config["Jwt:Key"] ?? throw new InvalidOperationException("Jwt:Key ayarını girin.");
        if (Encoding.UTF8.GetByteCount(key) < 32)
            throw new InvalidOperationException("Jwt:Key en az 32 bayt olmalı.");

        var roles = await users.GetRolesAsync(user);
        var claims = new List<Claim> { new(JwtRegisteredClaimNames.Sub, user.Id) };
        claims.AddRange(roles.Select(role => new Claim(ClaimTypes.Role, role)));
        var expires = DateTime.UtcNow.AddMinutes(15);
        var jwt = new JwtSecurityToken(
            issuer: config["Jwt:Issuer"] ?? throw new InvalidOperationException("Jwt:Issuer ayarını girin."),
            audience: config["Jwt:Audience"] ?? throw new InvalidOperationException("Jwt:Audience ayarını girin."),
            claims: claims,
            expires: expires,
            signingCredentials: new SigningCredentials(
                new SymmetricSecurityKey(Encoding.UTF8.GetBytes(key)), SecurityAlgorithms.HmacSha256));
        Response.Headers.CacheControl = "no-store";
        Response.Headers.Pragma = "no-cache";
        return Ok(new { accessToken = new JwtSecurityTokenHandler().WriteToken(jwt), expiresAtUtc = expires });
    }
}

API işlemlerini rolle koru

Liste ve detay herkese açıktır. POST, PUT ve DELETE için Bearer token ve Yonetici rolü gerekir. Token yoksa veya geçersizse 401, geçerli token’ın rolü yeterli değilse 403 döner. JWT süresi dolana kadar içindeki rol bilgisi geçerlidir. Rol değişikliğinin mevcut token’a anında yansıması için ayrıca iptal veya merkezi doğrulama tasarımı gerekir.

Controllers/Api/EtkinliklerApiController.cs
using Etkinlikler.Data;
using Etkinlikler.Models;
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Controllers.Api;

[ApiController]
[Route("api/etkinlikler")]
public class EtkinliklerApiController(EtkinlikDbContext db) : ControllerBase
{
    [HttpGet]
    public async Task<IActionResult> Listele([FromQuery] EtkinlikSorgusu istek, CancellationToken cancellationToken)
    {
        var sorgu = db.Etkinlikler.AsNoTracking().AsQueryable();
        if (!string.IsNullOrWhiteSpace(istek.Arama))
        {
            var arama = istek.Arama.Trim();
            sorgu = sorgu.Where(e => e.Ad.Contains(arama));
        }
        if (istek.EnAzKontenjan.HasValue)
            sorgu = sorgu.Where(e => e.Kontenjan >= istek.EnAzKontenjan.Value);

        var toplam = await sorgu.CountAsync(cancellationToken);
        var azalan = istek.Yon == "azalan";
        sorgu = istek.Sirala switch
        {
            "ad" when azalan => sorgu.OrderByDescending(e => e.Ad).ThenBy(e => e.Id),
            "ad" => sorgu.OrderBy(e => e.Ad).ThenBy(e => e.Id),
            "kontenjan" when azalan => sorgu.OrderByDescending(e => e.Kontenjan).ThenBy(e => e.Id),
            "kontenjan" => sorgu.OrderBy(e => e.Kontenjan).ThenBy(e => e.Id),
            _ when azalan => sorgu.OrderByDescending(e => e.Id),
            _ => sorgu.OrderBy(e => e.Id)
        };

        var kayitlar = await sorgu.Skip((istek.Sayfa - 1) * istek.SayfaBoyutu)
            .Take(istek.SayfaBoyutu).ToListAsync(cancellationToken);
        return Ok(new { istek.Sayfa, istek.SayfaBoyutu, toplamKayit = toplam, kayitlar });
    }

    [HttpGet("{id:int}")]
    public async Task<ActionResult<Etkinlik>> Getir(int id, CancellationToken cancellationToken)
    {
        var etkinlik = await db.Etkinlikler.AsNoTracking()
            .SingleOrDefaultAsync(e => e.Id == id, cancellationToken);
        return etkinlik is null ? NotFound() : Ok(etkinlik);
    }

    [Authorize(AuthenticationSchemes = JwtBearerDefaults.AuthenticationScheme, Roles = "Yonetici")]
    [HttpPost]
    public async Task<ActionResult<Etkinlik>> Ekle(
        [FromBody] EtkinlikFormu form, CancellationToken cancellationToken)
    {
        var etkinlik = new Etkinlik { Ad = form.Ad!, Kontenjan = form.Kontenjan!.Value };
        db.Etkinlikler.Add(etkinlik);
        await db.SaveChangesAsync(cancellationToken);
        return CreatedAtAction(nameof(Getir), new { id = etkinlik.Id }, etkinlik);
    }

    [Authorize(AuthenticationSchemes = JwtBearerDefaults.AuthenticationScheme, Roles = "Yonetici")]
    [HttpPut("{id:int}")]
    public async Task<IActionResult> Guncelle(
        int id, [FromBody] EtkinlikFormu form, CancellationToken cancellationToken)
    {
        await using var transaction = await db.Database.BeginTransactionAsync(cancellationToken);
        var kilitlenen = await db.Etkinlikler.Where(e => e.Id == id)
            .ExecuteUpdateAsync(set => set.SetProperty(e => e.Kontenjan, e => e.Kontenjan), cancellationToken);
        if (kilitlenen == 0)
            return NotFound();

        var kayitSayisi = await db.EtkinlikKayitlari.CountAsync(k => k.EtkinlikId == id, cancellationToken);
        if (form.Kontenjan!.Value < kayitSayisi)
            return Conflict(new { mesaj = "Kontenjan mevcut kayıt sayısından az olamaz.", kayitSayisi });

        var etkinlik = await db.Etkinlikler.SingleAsync(e => e.Id == id, cancellationToken);
        etkinlik.Ad = form.Ad!;
        etkinlik.Kontenjan = form.Kontenjan.Value;
        await db.SaveChangesAsync(cancellationToken);
        await transaction.CommitAsync(cancellationToken);
        return NoContent();
    }

    [Authorize(AuthenticationSchemes = JwtBearerDefaults.AuthenticationScheme, Roles = "Yonetici")]
    [HttpDelete("{id:int}")]
    public async Task<IActionResult> Sil(int id, CancellationToken cancellationToken)
    {
        await using var transaction = await db.Database.BeginTransactionAsync(cancellationToken);
        var kilitlenen = await db.Etkinlikler.Where(e => e.Id == id)
            .ExecuteUpdateAsync(set => set.SetProperty(e => e.Kontenjan, e => e.Kontenjan), cancellationToken);
        if (kilitlenen == 0)
            return NotFound();

        var etkinlik = await db.Etkinlikler.SingleAsync(e => e.Id == id, cancellationToken);
        db.Etkinlikler.Remove(etkinlik);
        await db.SaveChangesAsync(cancellationToken);
        await transaction.CommitAsync(cancellationToken);
        return NoContent();
    }
}

Bu derste API yazma uçları yalnızca Bearer şemasını kabul eder. Önceki derslerdeki çerez ve X-CSRF-TOKEN ile API yazma örnekleri bu sürümde JWT ile güncellenmelidir. MVC ekranları Identity çerezini ve kendi form doğrulama belirteçlerini kullanmaya devam eder.

Yerelde dene

ZIP içindeki Etkinlikler klasörüne gir. Yedinci dersteki veritabanı bağlantısı, migration ve yönetici hesabı hazır olmalı. Anahtar için aşağıdaki komut yeni bir rastgele değer üretir ve yerel User Secrets alanına yazar.

Terminal · macOS ve Linux
dotnet restore
dotnet user-secrets set 'Jwt:Key' "$(openssl rand -base64 48)"
dotnet user-secrets set 'Jwt:Issuer' 'dotnet-atolye'
dotnet user-secrets set 'Jwt:Audience' 'etkinlik-api'
ASPNETCORE_ENVIRONMENT=Development dotnet run --no-launch-profile --urls http://localhost:5089

PowerShell’de anahtarı güvenli bir rastgele değerle oluşturup aynı User Secrets ayarlarını gir. Ortam için $env:ASPNETCORE_ENVIRONMENT = "Development" kullan. Yerel HTTP adresi yalnızca eğitim ortamı içindir.

Token isteği · örnek
curl -X POST 'http://localhost:5089/api/token'   -H 'Content-Type: application/json'   -d '{"eposta":"yonetici@example.com","parola":"KENDI_PAROLANIZ"}'

Yanıttaki accessToken değerini istemcinin Authorization başlığına Bearer olarak ekle. Aşağıdaki yer tutucuyu kendi token’ınla değiştir. Komut satırı geçmişi bu tür değerleri saklayabileceğinden gerçek ortamlarda istemcinin güvenli gizli bilgi mekanizmasını kullan.

Yönetici isteği
curl -X POST 'http://localhost:5089/api/etkinlikler'   -H 'Authorization: Bearer TOKEN_DEGERI'   -H 'Content-Type: application/json'   -d '{"ad":"JWT Atölyesi","kontenjan":30}'

Test ve alıştırma

Örnek testleri geçici SQLite veritabanında gerçek Identity kullanıcıları oluşturur. Parola hatası, yönetici ve rolü olmayan kullanıcı, süresi dolmuş token, hatalı imza, issuer ve audience durumlarını doğrular. SQL Server üzerinde ayrıca entegrasyon testi gerekir.

Terminal · ZIP içindeki ders klasöründen
dotnet test Etkinlikler.Tests/Etkinlikler.Tests.csproj

Alıştırma olarak yönetici olmayan bir kullanıcı için token al ve POST isteğinin 403 döndürdüğünü gözlemle. Daha sonra süresi dolan token ile isteği tekrar dene.
