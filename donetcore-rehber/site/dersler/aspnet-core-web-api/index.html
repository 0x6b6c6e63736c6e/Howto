ASP.NET Core Web API

Etkinlikleri JSON olarak listele ve yönetici oturumuyla API üzerinden yeni etkinlik ekle.

.NET 10Ders 9Yaklaşık 35 dakika
Ön koşul

Yedinci dersteki yönetici hesabı ve SQL Server bağlantısı.

Örnek projeyi indir

API adresleri ve yanıtlar

API aynı EtkinlikDbContext ve SQL Server veritabanını kullanır. GET /api/etkinlikler listeyi JSON olarak, GET /api/etkinlikler/1 tek bir etkinliği döndürür. Bulunmayan kimlik 404 verir. POST /api/etkinlikler yönetici yetkisiyle etkinlik ekler ve 201 ile yeni kaydın adresini içeren Location başlığını döndürür.

[ApiController] JSON modelini doğrular. Ad 3–80 karakter, kontenjan 1–500 olmalıdır. Geçersiz istek 400 ve alan hata ayrıntıları döndürür. Oturum açılmamış yönetici isteği 401, rolü olmayan kullanıcı 403 alır.

API controller ve yönlendirme

ControllerBase JSON API yanıtları için kullanılır. AsNoTracking salt okunur liste ve detay sorgularını izleme yükü olmadan çalıştırır. POST için mevcut form modelindeki doğrulama kuralları kullanılır. Yeni kayıt SaveChangesAsync ile yazılır.

Controllers/Api/EtkinliklerApiController.cs
using Etkinlikler.Data;
using Etkinlikler.Models;
using Microsoft.AspNetCore.Antiforgery;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Controllers.Api;

[ApiController]
[Route("api/etkinlikler")]
public class EtkinliklerApiController(EtkinlikDbContext db) : ControllerBase
{
    [HttpGet]
    public async Task<ActionResult<IReadOnlyList<Etkinlik>>> Listele(CancellationToken cancellationToken)
    {
        var etkinlikler = await db.Etkinlikler.AsNoTracking()
            .OrderBy(e => e.Id).ToListAsync(cancellationToken);
        return Ok(etkinlikler);
    }

    [HttpGet("{id:int}")]
    public async Task<ActionResult<Etkinlik>> Getir(int id, CancellationToken cancellationToken)
    {
        var etkinlik = await db.Etkinlikler.AsNoTracking()
            .SingleOrDefaultAsync(e => e.Id == id, cancellationToken);
        return etkinlik is null ? NotFound() : Ok(etkinlik);
    }

    [Authorize(Roles = "Yonetici")]
    [HttpGet("form-belirteci")]
    public IActionResult FormBelirteci([FromServices] IAntiforgery antiforgery)
    {
        var token = antiforgery.GetAndStoreTokens(HttpContext);
        return Ok(new { token = token.RequestToken });
    }

    [Authorize(Roles = "Yonetici")]
    [ValidateAntiForgeryToken]
    [HttpPost]
    public async Task<ActionResult<Etkinlik>> Ekle(
        [FromBody] EtkinlikFormu form, CancellationToken cancellationToken)
    {
        var etkinlik = new Etkinlik { Ad = form.Ad!, Kontenjan = form.Kontenjan!.Value };
        db.Etkinlikler.Add(etkinlik);
        await db.SaveChangesAsync(cancellationToken);
        return CreatedAtAction(nameof(Getir), new { id = etkinlik.Id }, etkinlik);
    }
}

Program.cs içinde MVC servisleri zaten kayıtlıdır. Özellik tabanlı API adreslerini eşle ve çerezle gönderilen POST için belirteç başlığını tanımla.

Program.cs · ilgili satırlar
builder.Services.AddControllersWithViews();
builder.Services.AddAntiforgery(options => options.HeaderName = "X-CSRF-TOKEN");

// app.UseAuthentication() ve app.UseAuthorization() sonrasında
app.MapControllers();

API isteğini dene

ZIP dosyasını aç ve önce yedinci dersteki SQL Server bağlantısını, migration’ları ve yönetici hesabını hazırla. Yeni migration gerekmez. Uygulamayı başlat.

Terminal · ZIP içindeki ders klasöründen
ASPNETCORE_ENVIRONMENT=Development dotnet run --project Etkinlikler --no-launch-profile --urls http://localhost:5086

Listeyi terminalden iste.

Terminal
curl http://localhost:5086/api/etkinlikler

Yeni kayıt için aynı adreste tarayıcıdan yönetici olarak giriş yap. Giriş sonrasında tarayıcının geliştirici konsolunda aşağıdaki örneği çalıştır. İlk istek oturuma bağlı doğrulama belirtecini ve çerezini alır. İkinci istek bunlarla JSON gönderir. Bu örnek tarayıcıdaki mevcut Identity oturumunu kullanır.

Tarayıcı konsolu
const tokenYaniti = await fetch("/api/etkinlikler/form-belirteci");
const { token } = await tokenYaniti.json();

const yanit = await fetch("/api/etkinlikler", {
    method: "POST",
    headers: {
        "Content-Type": "application/json",
        "X-CSRF-TOKEN": token
    },
    body: JSON.stringify({ ad: "API Atölyesi", kontenjan: 30 })
});
console.log(yanit.status, yanit.headers.get("Location"), await yanit.json());

Başarılı yanıtta 201 ve oluşturulan etkinliğin JSON verisi görünür. Aynı etkinliği liste isteğinde de görebilirsin. Bağımsız istemciler için kimlik doğrulama ayrıca tasarlanmalıdır.

Test ve alıştırma

Test projesi geçici SQLite veritabanında listeleme, 401, 403, eksik belirteç, geçersiz veri ve başarılı 201 yanıtını kontrol eder. Testte kimlik test düzeniyle oluşturulur. SQL Server bağlantısı ve gerçek Identity oturumu ayrı entegrasyon testleriyle doğrulanmalıdır.

Terminal
dotnet test Etkinlikler.Tests/Etkinlikler.Tests.csproj

Alıştırma olarak detay adresine bulunmayan bir kimlik gönder ve 404 yanıtını incele. Ardından geçersiz kontenjan gönderip 400 yanıtındaki hata mesajını bul.
