Transaction ve eşzamanlı kayıt

Etkinliğe katılımcı kaydet. EF Core transaction’ı ve SQL Server kilidiyle iki eşzamanlı isteğin aynı son yeri almasını önle.

.NET 10 ve EF Core 10Ders 6Yaklaşık 40 dakika
Ön koşul

.NET 10 SDK ve beşinci dersteki SQL Server veritabanı. Eşzamanlılık deneyi için yazma yetkisi olan bir geliştirici veritabanı kullan.

Örnek projeyi indir

Son yer için iki istek gelirse

Kontenjanı 1 olan bir etkinliği düşün. İki istek aynı anda kayıt sayısını okursa ikisi de 0 görebilir. Farklı iki katılımcı için bileşik birincil anahtar çakışmaz, dolayısıyla iki ekleme de başarılı olabilir. SaveChangesAsync her yazmayı kendi içinde güvenli yürütür. Kontenjan kuralı ise önceki okumanın da aynı transaction içinde korunmasını gerektirir.

A isteğiB isteği
Etkinlik kilidini alır ve 0 kayıt görür.Aynı etkinliğin kilidini bekler.
Katılımcıyı ekler ve commit eder.Kilit açılınca sayımı yapar ve 1 kayıt görür.
Kayıt başarılı.Kontenjan dolu. Yeni kayıt açılmaz.

Kilidi önce alan istek değişebilir. Beklenen sonuç bir başarı ve bir dolu kontenjan yanıtıdır.

Sayım ve eklemeyi aynı transaction içinde yap

Örnek, SQL Server’da etkinlik kaydını UPDLOCK, HOLDLOCK ile okur. Bir etkinlik için ikinci kayıt isteği aynı kilidi almak zorunda kalır ve ilk transaction bitene kadar sayım adımına geçemez. ReadCommitted ile ikinci istek, kilidi aldıktan sonra güncel kayıt sayısını okur.

FromSql içindeki etkinlikId SQL parametresi olarak gönderilir. Sıra önemli. Önce etkinliği kilitle, sonra katılımcıyı ve çift kaydı kontrol et, ardından say ve ekle. CommitAsync başarılı değişikliği kalıcılaştırır. Erken dönüş veya hata durumunda await using commit edilmemiş transaction’ı kapatır ve kilit bırakılır.

Data/EtkinlikKayitServisi.cs
using System.Data;
using Etkinlikler.Models;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Data;

public enum KayitSonucu
{
    Basarili,
    EtkinlikBulunamadi,
    KatilimciBulunamadi,
    ZatenKayitli,
    KontenjanDolu
}

public sealed class EtkinlikKayitServisi(EtkinlikDbContext db)
{
    public async Task<KayitSonucu> KaydetAsync(
        int etkinlikId, int katilimciId, CancellationToken cancellationToken)
    {
        await using var transaction = await db.Database.BeginTransactionAsync(
            IsolationLevel.ReadCommitted, cancellationToken);

        var etkinlik = await db.Etkinlikler
            .FromSql($"""
                SELECT Id, Ad, Kontenjan
                FROM dbo.Etkinlikler WITH (UPDLOCK, HOLDLOCK)
                WHERE Id = {etkinlikId}
                """)
            .AsNoTracking()
            .SingleOrDefaultAsync(cancellationToken);

        if (etkinlik is null)
        {
            return KayitSonucu.EtkinlikBulunamadi;
        }

        if (!await db.Set<Katilimci>().AnyAsync(k => k.Id == katilimciId, cancellationToken))
        {
            return KayitSonucu.KatilimciBulunamadi;
        }

        var kayitlar = db.EtkinlikKayitlari.Where(k => k.EtkinlikId == etkinlikId);
        if (await kayitlar.AnyAsync(k => k.KatilimciId == katilimciId, cancellationToken))
        {
            return KayitSonucu.ZatenKayitli;
        }

        if (await kayitlar.CountAsync(cancellationToken) >= etkinlik.Kontenjan)
        {
            return KayitSonucu.KontenjanDolu;
        }

        db.EtkinlikKayitlari.Add(new EtkinlikKaydi
        {
            EtkinlikId = etkinlikId,
            KatilimciId = katilimciId
        });

        await db.SaveChangesAsync(cancellationToken);
        await transaction.CommitAsync(cancellationToken);
        return KayitSonucu.Basarili;
    }
}

EtkinlikId ve KatilimciId üzerindeki bileşik anahtar aynı katılımcının tekrar eklenmesine karşı veritabanı koruması sağlar. Kapasite garantisi için kayıt ekleyen bütün akışlar aynı etkinlik kilidini kullanmalıdır. Uygulamayı atlayan doğrudan SQL eklemeleri veya kontenjanı kayıt sayısının altına indiren ayrı güncellemeler bu kurala dahil edilmelidir.

Kayıt formunu bağla

Program.cs içinde kayıt servisini istek başına kaydet. Form, var olan bir etkinlik ve katılımcı seçtirir. POST action doğrulama belirtecini kontrol eder. Başarıdan sonra doluluk raporuna yönlendirir. Dolu kontenjan veya tekrar kayıt durumunda seçimleri ve hata mesajını formda gösterir.

Controllers/KayitlarController.cs
using Etkinlikler.Data;
using Etkinlikler.Models;
using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.Rendering;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Controllers;

public class KayitlarController(EtkinlikDbContext db, EtkinlikKayitServisi kayitServisi) : Controller
{
    [HttpGet]
    public Task<IActionResult> Ekle(CancellationToken cancellationToken)
        => FormuGosterAsync(new KatilimciKayitFormu(), cancellationToken);

    [HttpPost]
    [ValidateAntiForgeryToken]
    public async Task<IActionResult> Ekle(KatilimciKayitFormu form, CancellationToken cancellationToken)
    {
        if (!ModelState.IsValid)
        {
            return await FormuGosterAsync(form, cancellationToken);
        }

        var sonuc = await kayitServisi.KaydetAsync(
            form.EtkinlikId!.Value, form.KatilimciId!.Value, cancellationToken);

        if (sonuc == KayitSonucu.Basarili)
        {
            TempData["KayitMesaji"] = "Katılımcı kaydedildi.";
            return RedirectToAction("Doluluk", "Etkinlikler");
        }

        var mesaj = sonuc switch
        {
            KayitSonucu.EtkinlikBulunamadi => "Etkinlik bulunamadı.",
            KayitSonucu.KatilimciBulunamadi => "Katılımcı bulunamadı.",
            KayitSonucu.ZatenKayitli => "Bu katılımcı etkinliğe zaten kayıtlı.",
            _ => "Etkinliğin kontenjanı dolu."
        };

        ModelState.AddModelError(string.Empty, mesaj);
        return await FormuGosterAsync(form, cancellationToken);
    }

    private async Task<IActionResult> FormuGosterAsync(
        KatilimciKayitFormu form, CancellationToken cancellationToken)
    {
        var etkinlikler = await db.Etkinlikler.AsNoTracking().OrderBy(e => e.Ad).ThenBy(e => e.Id)
            .ToListAsync(cancellationToken);
        var katilimcilar = await db.Set<Katilimci>().AsNoTracking().OrderBy(k => k.Ad).ThenBy(k => k.Id)
            .ToListAsync(cancellationToken);

        ViewBag.Etkinlikler = new SelectList(etkinlikler, nameof(Etkinlik.Id), nameof(Etkinlik.Ad));
        ViewBag.Katilimcilar = new SelectList(katilimcilar, nameof(Katilimci.Id), nameof(Katilimci.Ad));
        return View(nameof(Ekle), form);
    }
}

Son yer deneyini iki ayrı DbContext ile çalıştır

Deney her çalıştırmada geliştirici veritabanına kontenjanı 1 olan yeni bir Son yer deneyi etkinliği ekler. İki mevcut katılımcı adına Task.WhenAll ile kayıt denemelerini bir araya getirir. Her deneme kendi bağımlılık kapsamı, DbContext ve transaction’ıyla çalışır. Bu, iki ayrı uygulama isteğinin hizmet katmanını temsil eder.

Terminal · Eşzamanlı kayıt deneyi
ASPNETCORE_ENVIRONMENT=Development dotnet run --no-launch-profile -- --kayit-deneyi
Beklenen çıktı · Kazananın sırası değişebilir
Etkinlik #3: Basarili, KontenjanDolu. Toplam kayıt: 1.
Data/KayitDeneyi.cs
using Etkinlikler.Models;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Data;

public static class KayitDeneyi
{
    public static async Task CalistirAsync(IServiceProvider services, CancellationToken cancellationToken)
    {
        await using var kontrolScope = services.CreateAsyncScope();
        var db = kontrolScope.ServiceProvider.GetRequiredService<EtkinlikDbContext>();
        var katilimcilar = await db.Set<Katilimci>().OrderBy(k => k.Id).Select(k => k.Id)
            .Take(2).ToListAsync(cancellationToken);
        if (katilimcilar.Count != 2)
        {
            throw new InvalidOperationException("Deney için en az iki katılımcı gerekir.");
        }

        var etkinlik = new Etkinlik { Ad = "Son yer deneyi", Kontenjan = 1 };
        db.Etkinlikler.Add(etkinlik);
        await db.SaveChangesAsync(cancellationToken);

        async Task<KayitSonucu> DeneAsync(int katilimciId)
        {
            await using var scope = services.CreateAsyncScope();
            var kayit = scope.ServiceProvider.GetRequiredService<EtkinlikKayitServisi>();
            return await kayit.KaydetAsync(etkinlik.Id, katilimciId, cancellationToken);
        }

        var sonuclar = await Task.WhenAll(DeneAsync(katilimcilar[0]), DeneAsync(katilimcilar[1]));
        var kayitSayisi = await db.EtkinlikKayitlari.CountAsync(
            k => k.EtkinlikId == etkinlik.Id, cancellationToken);

        Console.WriteLine($"Etkinlik #{etkinlik.Id}: {string.Join(", ", sonuclar)}. Toplam kayıt: {kayitSayisi}.");
        if (kayitSayisi != 1 || !sonuclar.Contains(KayitSonucu.Basarili)
            || !sonuclar.Contains(KayitSonucu.KontenjanDolu))
        {
            throw new InvalidOperationException("Deney beklenen sonucu vermedi.");
        }
    }
}

Deney, iki sonucu ve veritabanındaki kayıt sayısını kontrol eder. Çıktıdaki etkinlik kimliği veritabanına göre değişir. Deney etkinliği raporda kalır.

Alıştırma

Deneyde kontenjanı 2 yap. İki farklı katılımcıyla her iki işlemin başarılı, kayıt sayısının 2 olmasını bekleyecek şekilde doğrulamayı değiştir. Ardından boş bir test etkinliğinde iki denemeye de aynı katılımcı kimliğini gönder. Bir başarılı ve bir tekrar kayıt sonucu bekle.
