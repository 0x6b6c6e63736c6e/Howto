SQL Server entegrasyon testleri

JWT, rol, doğrulama ve son kontenjan davranışını ayrı bir SQL Server test veritabanıyla sınayalım.

.NET 10 ve SQL ServerDers 17Yaklaşık 45 dakika
Ön koşul

On altıncı ders, .NET 10 SDK ve boş bir SQL Server test veritabanı.

Örnek projeyi indir

Gerçek sağlayıcıyla neyi test ediyoruz?

Test, ASP.NET Core test sunucusu ile gerçek SQL Server bağlantısını birleştirir. EF Core migration’larını uygular ve Identity kullanıcıları oluşturur. JWT üretimi, yönetici ve üye rolü, model doğrulaması ve etkinlik ekleme HTTP üzerinden sınanır.

Son yer senaryosunda iki ayrı kapsam ve DbContext aynı anda farklı katılımcılar için kayıt servisini çağırır. Bir başarı, bir dolu kontenjan sonucu ve veritabanında bir kayıt beklenir. Bu test servis katmanını çalıştırır. MVC formundan uçtan uca eşzamanlı istek testi değildir.

Ayrı test veritabanını hazırla

SQL Server üzerinde bu test için yeni ve boş bir veritabanı oluştur. Bağlantıyı ETKINLIK_TEST_SQL ortam değişkeniyle ver. Test tablolar varsa çalışmayı durdurur. Migration ve test verileri test sonunda kalır. Yeniden çalıştırmak için başka bir boş test veritabanı kullan.

Bağlantıdaki kullanıcıya bu veritabanında migration uygulama ve veri yazma yetkisi ver. Parola içeren bağlantıyı güvenli ortam değişkeni yönetimiyle sağla. Bu bilgisayardaki bağlantı örneği kendinden imzalı sertifika kullanan yerel geliştirme sunucusu içindir.

Terminal · macOS ve Linux
export ETKINLIK_TEST_SQL='Server=SUNUCU;Database=AYRI_BOS_TEST_DB;User Id=KULLANICI;Password=PAROLA;Encrypt=True;TrustServerCertificate=True'
dotnet test Etkinlikler.Tests/Etkinlikler.Tests.csproj --filter FullyQualifiedName~SqlServerEntegrasyonTestleri

PowerShell’de aynı bağlantıyı $env:ETKINLIK_TEST_SQL ile ayarla. SQL Server container imajları Microsoft tarafından Linux x86-64 üzerinde desteklenir. Apple Silicon kullanıyorsan desteklenen uzak veya ayrı bir SQL Server’a bağlanabilirsin.

Entegrasyon testi

WebApplicationFactory uygulamayı test sunucusunda başlatır. Veritabanı yapılandırması test bağlantısıyla değiştirilir. İstekler gerçek Identity ve JWT doğrulamasından geçer. TaskCompletionSource iki kayıt denemesini ortak başlangıç noktasında serbest bırakır. SQL Server zamanlaması değişebilir ve test tekrarlı çalıştırılarak gözlemlenebilir.

Etkinlikler.Tests/SqlServerEntegrasyonTestleri.cs
using System.Net;
using System.Net.Http.Headers;
using System.Net.Http.Json;
using System.Security.Cryptography;
using Etkinlikler.Data;
using Etkinlikler.Models;
using Microsoft.AspNetCore.Hosting;
using Microsoft.AspNetCore.Identity;
using Microsoft.AspNetCore.Mvc.Testing;
using Microsoft.Data.SqlClient;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.DependencyInjection;
using Xunit;

namespace Etkinlikler.Tests;

public class SqlServerEntegrasyonTestleri
{
    [Fact]
    public async Task Jwt_roller_dogrulama_ve_son_yer()
    {
        var connection = Environment.GetEnvironmentVariable("ETKINLIK_TEST_SQL")
            ?? throw new InvalidOperationException("ETKINLIK_TEST_SQL ile boş test veritabanının bağlantısını ayarlayın.");
        var connectionBuilder = new SqlConnectionStringBuilder(connection);
        if (string.IsNullOrWhiteSpace(connectionBuilder.InitialCatalog))
            throw new InvalidOperationException("Bağlantıda ayrı bir test veritabanı belirtilmeli.");

        // Önceden var olan tabloya veya veriye dokunulmaz.
        await using (var sql = new SqlConnection(connection))
        {
            await sql.OpenAsync();
            await using var check = sql.CreateCommand();
            check.CommandText = "SELECT COUNT(*) FROM sys.tables WHERE is_ms_shipped = 0";
            if (Convert.ToInt32(await check.ExecuteScalarAsync()) != 0)
                throw new InvalidOperationException("Test için tablo içermeyen boş bir veritabanı seçin.");
        }

        var key = Convert.ToBase64String(RandomNumberGenerator.GetBytes(48));
        await using var app = new WebApplicationFactory<Program>().WithWebHostBuilder(builder =>
        {
            builder.UseEnvironment("Development");
            builder.ConfigureAppConfiguration((_, config) => config.AddInMemoryCollection(
                new Dictionary<string, string?>
                {
                    ["ConnectionStrings:EtkinlikDb"] = connection,
                    ["Jwt:Key"] = key,
                    ["Jwt:Issuer"] = "entegrasyon",
                    ["Jwt:Audience"] = "etkinlik-test"
                }));
        });

        int etkinlikId;
        using (var scope = app.Services.CreateScope())
        {
            var db = scope.ServiceProvider.GetRequiredService<EtkinlikDbContext>();
            await db.Database.MigrateAsync();
            var eventItem = new Etkinlik { Ad = "Eşzamanlı test", Kontenjan = 1 };
            db.Etkinlikler.Add(eventItem);
            await db.SaveChangesAsync();
            etkinlikId = eventItem.Id;

            var roles = scope.ServiceProvider.GetRequiredService<RoleManager<IdentityRole>>();
            var users = scope.ServiceProvider.GetRequiredService<UserManager<IdentityUser>>();
            Assert.True((await roles.CreateAsync(new IdentityRole("Yonetici"))).Succeeded);
            var admin = new IdentityUser { UserName = "admin@test.local", Email = "admin@test.local" };
            var member = new IdentityUser { UserName = "uye@test.local", Email = "uye@test.local" };
            Assert.True((await users.CreateAsync(admin, "Test!12345")).Succeeded);
            Assert.True((await users.CreateAsync(member, "Test!12345")).Succeeded);
            Assert.True((await users.AddToRoleAsync(admin, "Yonetici")).Succeeded);
        }

        using var client = app.CreateClient(new WebApplicationFactoryClientOptions { AllowAutoRedirect = false });
        async Task<string> TokenAsync(string email)
        {
            using var response = await client.PostAsJsonAsync("/api/token", new { eposta = email, parola = "Test!12345" });
            Assert.Equal(HttpStatusCode.OK, response.StatusCode);
            return (await response.Content.ReadFromJsonAsync<TokenCevabi>())!.AccessToken;
        }

        using (var anonymous = await client.PostAsJsonAsync("/api/etkinlikler", new { ad = "Entegrasyon", kontenjan = 10 }))
            Assert.Equal(HttpStatusCode.Unauthorized, anonymous.StatusCode);
        client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", "gecersiz-token");
        using (var invalidToken = await client.PostAsJsonAsync("/api/etkinlikler", new { ad = "Entegrasyon", kontenjan = 10 }))
            Assert.Equal(HttpStatusCode.Unauthorized, invalidToken.StatusCode);
        client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", await TokenAsync("uye@test.local"));
        using (var forbidden = await client.PostAsJsonAsync("/api/etkinlikler", new { ad = "Entegrasyon", kontenjan = 10 }))
            Assert.Equal(HttpStatusCode.Forbidden, forbidden.StatusCode);
        client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", await TokenAsync("admin@test.local"));
        using (var invalid = await client.PostAsJsonAsync("/api/etkinlikler", new { ad = "AB", kontenjan = 0 }))
            Assert.Equal(HttpStatusCode.BadRequest, invalid.StatusCode);
        using (var created = await client.PostAsJsonAsync("/api/etkinlikler", new { ad = "Entegrasyon", kontenjan = 10 }))
            Assert.Equal(HttpStatusCode.Created, created.StatusCode);

        using var timeout = new CancellationTokenSource(TimeSpan.FromSeconds(30));
        var gate = new TaskCompletionSource(TaskCreationOptions.RunContinuationsAsynchronously);
        async Task<KayitSonucu> KaydetAsync(int katilimci)
        {
            await using var scope = app.Services.CreateAsyncScope();
            var service = scope.ServiceProvider.GetRequiredService<EtkinlikKayitServisi>();
            await gate.Task.WaitAsync(timeout.Token);
            return await service.KaydetAsync(etkinlikId, katilimci, timeout.Token);
        }
        var ilk = KaydetAsync(1);
        var ikinci = KaydetAsync(2);
        gate.SetResult();
        var results = await Task.WhenAll(ilk, ikinci);
        Assert.Equal(1, results.Count(r => r == KayitSonucu.Basarili));
        Assert.Equal(1, results.Count(r => r == KayitSonucu.KontenjanDolu));
        using (var scope = app.Services.CreateScope())
        {
            var db = scope.ServiceProvider.GetRequiredService<EtkinlikDbContext>();
            Assert.Equal(1, await db.EtkinlikKayitlari.CountAsync(k => k.EtkinlikId == etkinlikId));
        }
    }

    private sealed record TokenCevabi(string AccessToken);
}

Kayıt sorgusu ve kilit

On dördüncü derste eklenen Aciklama alanı, FromSql ile varlık yükleyen sorgunun seçtiği sütunlara da eklenmelidir. Bu örnekte eksik sütun düzeltildi. UPDLOCK, HOLDLOCK ile aynı etkinlik üzerindeki kayıt işlemleri transaction boyunca sıraya girer.

Data/EtkinlikKayitServisi.cs
using System.Data;
using Etkinlikler.Models;
using Microsoft.EntityFrameworkCore;

namespace Etkinlikler.Data;

public enum KayitSonucu
{
    Basarili,
    EtkinlikBulunamadi,
    KatilimciBulunamadi,
    ZatenKayitli,
    KontenjanDolu
}

public sealed class EtkinlikKayitServisi(EtkinlikDbContext db)
{
    public async Task<KayitSonucu> KaydetAsync(
        int etkinlikId, int katilimciId, CancellationToken cancellationToken)
    {
        await using var transaction = await db.Database.BeginTransactionAsync(
            IsolationLevel.ReadCommitted, cancellationToken);

        var etkinlik = await db.Etkinlikler
            .FromSql($"""
                SELECT Id, Ad, Kontenjan, Aciklama
                FROM dbo.Etkinlikler WITH (UPDLOCK, HOLDLOCK)
                WHERE Id = {etkinlikId}
                """)
            .AsNoTracking()
            .SingleOrDefaultAsync(cancellationToken);

        if (etkinlik is null)
        {
            return KayitSonucu.EtkinlikBulunamadi;
        }

        if (!await db.Set<Katilimci>().AnyAsync(k => k.Id == katilimciId, cancellationToken))
        {
            return KayitSonucu.KatilimciBulunamadi;
        }

        var kayitlar = db.EtkinlikKayitlari.Where(k => k.EtkinlikId == etkinlikId);
        if (await kayitlar.AnyAsync(k => k.KatilimciId == katilimciId, cancellationToken))
        {
            return KayitSonucu.ZatenKayitli;
        }

        if (await kayitlar.CountAsync(cancellationToken) >= etkinlik.Kontenjan)
        {
            return KayitSonucu.KontenjanDolu;
        }

        db.EtkinlikKayitlari.Add(new EtkinlikKaydi
        {
            EtkinlikId = etkinlikId,
            KatilimciId = katilimciId
        });

        await db.SaveChangesAsync(cancellationToken);
        await transaction.CommitAsync(cancellationToken);
        return KayitSonucu.Basarili;
    }
}

Test sonucunu yorumla

Başarılı çalışmada anonim ve geçersiz token için 401, üye için 403, geçersiz giriş için 400 ve yönetici eklemesi için 201 doğrulanır. Son yer testinde iki sonuçtan biri Basarili, diğeri KontenjanDolu olmalı ve veritabanındaki kayıt sayısı 1 olmalıdır.

Bu ders hazırlanırken SQL Server bağlantısı bulunmadığından gerçek sunucu testi çalıştırılamadı. Proje derlendi ve önceki SQLite testleri geçti. Testin SQL Server sonucu kendi ortamında çalıştırıldığında belirlenir.
