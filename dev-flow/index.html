        03 / Kritik Ayrım
        
En Çok Karıştırılan 4 Terim

        

          Günlük ekip konuşmalarında sıkça birbirinin yerine kullanılan Build, Publish, Deploy ve Release kavramlarının kesin sınırları:
        

      


      
      

        
        

          

            

              
01

              DERLEME
            

            
Build

            

              Kodu çalışır hale getirir (derler). Kaynak kodları makinenin veya tarayıcının anlayacağı optimize paketlere dönüştürür.
            

          

          

            Örn: npm run build
          

        


        
        

          

            

              
02

              YAYINLAMA
            

            
Publish

            

              Derlenmiş çıktıyı dağıtılabilir bir yere (paket deposu, klasör, mağaza) koyar. Henüz sunucuda çalışmaz, erişime hazırdır.
            

          

          

            Örn: npm publish / docker push
          

        


        
        

          

            

              
03

              KURULUM
            

            
Deploy

            

              Çıktıyı sunucuya kurar ve çalıştırır. Uygulama artık hedef ortamda (Staging veya Production) fiziksel olarak ayaktadır.
            

          

          

            Örn: kubectl apply -f deploy.yml
          

        


        
        

          

            

              
04

              KULLANIMA AÇMA
            

            
Release

            

              Çalışan yeni sürümü kullanıcılara açar. Teknik kurulumdan bağımsız olarak ürünün iş kararıyla son kullanıcıya sunulmasıdır.
            

          

          

            Örn: featureFlag.enable("v2")
          

        

      


      
      

        

          
        

        

          
Önemli Not: Her Deploy bir Release değildir!

          

            Bir kodu gece yarısı canlı sunucuya deploy edip, özelliği gizli tutarak (Feature Flag ile) ertesi sabah kullanıcılara Release edebilirsiniz. Böylece teknik kurulum riskini ürün lansmanından ayırmış olursunuz.
